## 闸门 G2.4 · 自检（新机第一次上电）

```bash
# 仿真先跑一遍，确认命令和判据
modkit --sim selftest --expect 1,2,3,4,5,6

# 真机：每个关节转 5°，到位误差 ≤1.5°，超温/故障立即停
modkit --port /dev/ttyUSB0 selftest --expect 1,2,3,4,5,6 --amp 5 --tol 1.5
```

输出逐关节表格 + `selftest.json`。判据：

- 扫描不到 ID → 停（查线/ID）
- 故障位非 0 → 停（先修，不要"再试一次"）
- 温度 ≥55℃ → 停
- 到位误差 >1.5° → 该关节不合格（先查是否卡滞/零位）

## 闸门 G2.5 · 标定（每个关节 10 分钟）

零位和限位不标，后面所有坐标都是错的。**先仿真跑通，再上真机**：

```bash
# 不需要硬件，先确认命令和换算没问题
python -m modkit.cli --sim calib --action scan
python -m modkit.cli --sim calib --action limits --id 1 --lo 0 --hi 180
python -m modkit.cli --sim calib --action zero --id 1 --name yaw --deg 90 --save calibration.json
python -m modkit.cli --sim calib --action verify --file calibration.json

# 真机
python -m modkit.cli --port /dev/ttyUSB0 --action limits --id 1 --lo 0 --hi 180
```

判据：`verify` 三个点的误差都 <2°；`limits` 不报故障（报故障说明撞限位了，
把 `--hi` 降 10° 重测）。标定文件随机器存档，换舵机必须重标。

细节见 [18-质检与验收](18-质检与验收.md) §4.1。

**速度寄存器标定（上车第一件事）**：`speed_unit` 默认 1.0 是占位值。
做法：发 `Speed = 1000`，让轮子空转 10 秒，数圈数 → `rpm` →
`speed_unit = 1000 / (rpm/60 × 4096)`。算出来填进 `DriveConfig::speed_unit`，
再把上面那条"标定"测一遍。不标定就做闭环 = 用一个错的尺子量长度。
