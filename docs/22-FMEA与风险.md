# 22 · FMEA 与风险

> 失效模式分析（FMEA）不是走流程：它回答"**最可能怎么坏、坏了多严重、怎么提前发现**"。
> 打分：S 严重度 / O 发生度 / D 难检度，各 1–10；RPN = S×O×D。RPN ≥ 100 必须处理。

## 1. 评分表（本项目的口径）

| 分 | S 严重度 | O 发生度 | D 难检度 |
|---|---|---|---|
| 9–10 | 伤人 / 烧毁 | 几乎必发生 | 装完才发现 |
| 7–8 | 整机不可用 | 经常 | 整机测试才发现 |
| 5–6 | 功能降级 | 有时 | 单件检验能发现 |
| 3–4 | 需返工 | 偶尔 | 装配时能发现 |
| 1–2 | 外观/轻微 | 极少 | 一眼可见 |

## 3. 必须处理（RPN ≥ 150）

1. **#1 堵转**：已有固件限流（`umax=300`、积分限幅），但**没有实测数据**。
   动作：Q3 堵转测试记录电流/温度，连续 3 台通过后降级。
2. **#2 上位机死机**：物理急停已进 BOM（¥8），接线见 [03](03-配电与线束.md) §3.5。
3. **#4 螺母拉脱**：工装 + 拉力抽检（每批 3 件）。
4. **#9 电池过放**：确认电池保护板截止电压 9.0V；加固件低压报警（<10.5V 蜂鸣）。
5. **#10 线束磨损**：装配手册加"线束走向图"（待补），轮边加波纹管。

## 5. 残余风险（接受）

- 没有碰撞检测：撞到人会疼，但力矩限制在 2.94 N·m，且急停可断电
- 没有功能安全认证（SIL/PL）：这是教学/原型机，不是工业设备
- PETG 蠕变：长期负载下关节会松，建议每 200 小时复检
