## 3. bring-up 怎么用

```bash
modkit bringup --action list
modkit bringup --action init --serial M1-2026-0001 --operator 老王
modkit bringup --action record --step 2 --result pass --evidence logs/scan.txt
modkit bringup --action status
modkit bringup --action verify
```

状态只认 `pass`；`simulated` 永远显示"0/5 物理闸门"。
第 10 步真机 mission 仍要求先过 1–9，且急停在场。

## 4. 发布包

```bash
python tools/release.py --version 1.2.0 --out dist
python tools/release.py --check --out dist
```

生成：

- `modkit-v1.2.0-production.zip`（文档、图纸、BOM、工具）
- `modkit-v1.2.0-cad.zip`（单件 + 4 张完整拼盘）
- `modkit-v1.2.0-web.zip`
- `modkit-v1.2.0-render.zip`
- `SHA256SUMS`
