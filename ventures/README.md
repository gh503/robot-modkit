# Ventures · 从 modkit 孵化的独立应用

这里放的是**有独立商业逻辑、可独立运行/拆分**的应用，不是 modkit 的库模块。
每个 venture 必须自带：

- `pyproject.toml` / 自己的 CLI / 测试；
- 客户、价值、定价、单位经济；
- 模型假设、验证计划、边界；
- 可复制为独立仓库的 README。

| 项目 | 状态 | 客户 | 一句话 |
|---|---|---|---|
| [AquaTwin](aquatwin/README.md) | 0.1.0 MVP | 泳池服务商/OEM/物业 | 把泳池清洗的覆盖/工时/能耗/成本算成可解释报告 |

## 准入标准

1. 有明确付费方，不是“技术 demo”；
2. 能独立运行，不依赖 modkit 的私有 API；
3. 有可证伪的验证计划，不把假设写成实测；
4. 有单位经济/定价，不把 TAM 当收入；
5. 能拆成独立仓库，不靠母项目“顺手维护”。

不满足就不放进 `ventures/`，留在 `docs/` 当方向研究。
