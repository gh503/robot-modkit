# 83 · 仿真实验环境

> 状态：**v1.32.0 已实现**。目标：把世界、流体、传感器、机器人任务组合成**可重复的
> 实验**：同一份 JSON + 同一组参数，跑出同一份指标；改一个变量，能解释差异。
> 这是工程级降阶实验台，不是认证 CFD/刚体耦合；物理闸门 **0/5**。

## 83.1 实验由什么组成

| 层 | JSON 字段 | 说明 |
|---|---|---|
| 空间 | `objects` | 地面/池体/管/台面/障碍；碰撞体元数据 |
| 流体 | `fluids` | 类型、材料、液位、温度、盐度、流量 |
| 边界 | `metadata`/`sources` | 点源/点汇、水箱出口、管道粗糙度 |
| 传感器 | `sensors` | level/pressure/flow/temperature；无模型明确 `modeled:false` |
| 机器人 | `robot` | 装配引用、位姿、任务；阻力/浮力参数在 `metadata.robot` |
| 时间 | CLI `--duration/--dt` | 显式时长/步长；CFL 自动限幅 |
| 网格 | CLI `--dx` | 浅水离散；越小越慢，默认 0.2m |

## 83.2 三步跑一个实验

```bash
cd software

# 1. 生成/校验世界
../.venv/bin/python -m modkit.cli world init --preset pool --out ../out/world-pool.json
../.venv/bin/python -m modkit.cli world validate --file ../out/world-pool.json

# 2. 跑 5 秒
../.venv/bin/python -m modkit.cli world run \
  --file ../out/world-pool.json --duration 5 --dx 0.2 --frame-every 10 \
  --out ../out/exp-pool

# 3. 看结果
cat ../out/exp-pool/report.md
```

输出：

| 文件 | 内容 |
|---|---|
| `metrics.json` | 每种流体的体积/水深/速度/误差/CFL；管道压降；传感器；机器人阻力/浮力 |
| `frames.json` | 浅水高度场帧（查看器可载入） |
| `sensors.csv` | 传感器读数 + `modeled` + 备注 |
| `report.md` | 人读报告，含模型边界 |

## 83.3 泳池实验示例

默认 `pool`：

- 池体 8×4×1.5m，水位 80%（1.2m），26°C，2ppt；
- 38.4m³ 水；level/pressure/temperature/turbidity 传感器；
- `world run` 用 2D 浅水，闭边界，初始静水；5s 内体积误差应接近 0。

改一个变量做对照：

```bash
# 水温 4°C：粘度上升，阻力/泵压变化
python3 - <<'PY'
import json
p='../out/world-pool.json'
w=json.load(open(p))
w['fluids'][0]['temperature_c']=4
json.dump(w,open('../out/world-pool-cold.json','w'),ensure_ascii=False,indent=2)
PY
../.venv/bin/python -m modkit.cli world run --file ../out/world-pool-cold.json \
  --duration 2 --out ../out/exp-pool-cold
```

注意：浅水求解器本身不把温度放进动量方程；温度只影响材料报告/传感器/阻力估算。
要研究温度对流动的影响，需要扩展粘性/浮力项，或接外部 CFD。

## 83.6 传感器与“不伪造”

| 类型 | 模型 | 说明 |
|---|---|---|
| `level` | ✅ | 流体深度 |
| `pressure` | ✅ | 底部表压 `ρgh` |
| `flow` | ✅ | 场景给定流量（管道/补水） |
| `temperature` | ✅ | 场景温度 |
| `turbidity` | ❌ | 没有颗粒/水质模型；`modeled:false` |
| `camera`/`imu` | ❌ | 由 `simui`/其他链路提供 |

报告不会把 `null` 写成 0；`sensors.csv` 有 `modeled` 列。任何“实测”必须来自硬件日志。

## 83.7 回归与参数敏感性

`metrics.json` 是确定性输出（同一输入/版本），适合做回归基线：

```bash
cp ../out/exp-pool/metrics.json ../out/baseline.json
# 改参数/代码后重跑
../.venv/bin/python - <<'PY'
import json
a=json.load(open('../out/baseline.json')); b=json.load(open('../out/exp-pool/metrics.json'))
for k in a['fluids']:
    va=a['fluids'][k].get('metrics',{}); vb=b['fluids'][k].get('metrics',{})
    for x in ('volume_m3','max_depth_m','dp_total_pa'):
        if x in va and x in vb:
            rel=abs(va[x]-vb[x])/max(1e-12,abs(va[x]))
            print(k,x,va[x],vb[x],f'{rel:.2e}')
PY
```

建议基线只比较**同网格/同时长**；改 `dx`/`dt` 会改变离散误差。

## 83.8 实验设计模板

1. **问题**：例如“泵从 1.5L/s 提到 2.5L/s，20mm 管压降是否超 30kPa？”
2. **固定**：几何、流体、温度、粗糙度、网格、时长。
3. **变量**：流量（或管径/液位/材料）。
4. **指标**：压降、Re、泵功率、排空时间、体积误差。
5. **判据**：写进实验 JSON 的 `metadata` 或外部表格；不要事后改判据。
6. **复现**：保存世界 JSON + 命令行 + 版本号。
7. **升级**：关键结论必须用实物/外部 CFD 复核，才能进设计冻结。

| 水下/养殖 | 海水密度/浮力/阻力 | 推进器选型、系泊载荷 |

## 83.10 边界

- 浅水是 2D 降阶模型；不含气泡/破碎/多相/波浪谱；
- 水箱 0D、管道稳态；不含水锤/空化/磨损；
- 传感器只实现 level/pressure/flow/temperature；
- 机器人阻力/浮力需在 `metadata.robot` 给面积/体积；没给就明确“不估算”；
- 世界/流体参数未标定；不能替代水池试验、安规、第三方认证；
- 物理闸门仍 **0/5**。
