## 3. 五分钟演示

```bash
modkit simui --open
```

1. 拖"线速度"到 60，点"运行"：俯视图机器人前进，曲线电压下降；
2. 拉"打滑"到 1.0：轮子转、车不动；
3. 拖"摩擦 μ"到 0.05，把机器人开到方块旁，合夹爪：状态卡显示"滑落"；
4. 场景回放选 `mission_onboard.json`，运行 → 回放：导航、车载相机、抓取、搬运；
5. 看相机面板绿框随视角变化；切"车载/俯视"。

## 4. 边界（不该被误读为能力）

- 接触只判"掉/不掉"，没有变形、滑动过程、六维力；
- 相机无畸变、无安装倾角、无运动模糊；手眼外参是"真值"；
- 参数辨识只覆盖编码器/电池，摩擦/回差仍需专用标定；
- 工作台是 2D Canvas，不是 3D 实时；
- 仿真通过 ≠ 实物通过，物理闸门仍 0/5（docs/42）。

## 5. 结论

**仿真开发工作台已落地**：不开硬件、不开 IDE，浏览器里就能注入故障、跑场景、
看相机、回放轨迹、导出数据；命令行能回归、扫参数、反推真机参数。
剩余是"更真的物理"和"真机标定"，属于后续迭代，不是这条目标的缺口。
