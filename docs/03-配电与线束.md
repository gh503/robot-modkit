# 02 · 配电与线束 v0.1

## 1. 电流预算（这是选电源的唯一依据）

数据来自 ST-3215-C018 规格：[DS] 空载 180 mA @12V，堵转 2.7 A @12V，额定扭矩 10 kg·cm。

| 工况 | 每舵机 | 4 舵机合计 | 说明 |
|---|---|---|---|
| 待机（卸力） | ~60 mA | 0.24 A | 只维持电路 |
| 空载运动 | 0.18 A | 0.72 A | 教学演示最常见 |
| 额定负载 | ~1.2 A | 4.8 A | 抓取轻物 |
| 双关节堵转 | 2.7 A | 5.4 A | 撞限位、夹死 |
| 四关节同时堵转 | 2.7 A | **10.8 A** | 只发生在故障或误操作，但电源必须扛住 3 秒 |

**结论**：

- 台面调试用 **12V / 5A** 够日常，但**必须做软件限流**（见 §4），否则一旦撞死就掉压复位。
- 想完全不担心，直接买 **12V / 10A**（贵约 ¥30），或者磷酸铁锂 3S/4S 方案（超本阶段预算，暂不做）。

## 2. 压降核算（线径不是随便选的）

铜线电阻 ≈ 0.0175 Ω·mm²/m。按环路长度（去+回）算：

| 线段 | 线径 | 环路长 | 电阻 | 峰值电流 | 压降 |
|---|---|---|---|---|---|
| 电源 → 配电板 | 18 AWG (0.82mm²) | 1.6 m | 0.034 Ω | 10.8 A | **0.37 V** |
| 配电板 → 末端舵机 | 22 AWG (0.33mm²) | 1.2 m | 0.064 Ω | 2.7 A | 0.17 V |
| 舵机原厂 15cm 线 | 26 AWG | 0.3 m | 0.016 Ω | 2.7 A | 0.04 V |

累计最坏 0.58 V：12.0 V → 11.4 V，仍在 9–12.6 V 工作范围内。
但**如果主线段用 22 AWG，压降会到 1.3 V 以上**，低电压保护（0x0F 默认 4.0V）虽不触发，舵机会明显掉力、抖动。**主线段必须 18 AWG 或更粗。**

## 3. 配电方案（v0.1 用端子排，不画 PCB）

```
             ┌──────────────┐
 12V/5A ─────┤ DC 座 + SS34 ├──┬── 1000µF/25V ── GND
 适配器      └──────────────┘  │
                               ├── 8A 自恢复保险 ── 主母线 V+
                               │
                     ┌─────────┴─────────┐
                     │   配电端子排      │
                     │  V+  ×6  GND ×6   │
                     └──┬───┬───┬───┬────┘
             ┌──────────┘   │   │   └──────────┐
        2A 保险         2A 保险 2A 保险      2A 保险
             │            │   │               │
         舵机1         舵机2 舵机3          舵机4
             │            │   │               │
             └────────────┴───┴───────────────┘  ← DATA 菊花链，不是星形
```

**关键点**

1. **DATA 只有一条链**：主控 TX/RX 经收发器接舵机 1，舵机 1 的下一根接舵机 2…… 末端悬空。
2. **每个舵机支路单独 2A 自恢复保险**：一个舵机堵转不会拖垮整条母线。
3. **1000µF 电解电容**放在配电板入口：吸收舵机换向的电流尖峰，防止主控复位。
4. **主控 5V 由独立降压模块供给**（12V→5V 2A），不要从舵机支路取电。
5. 地线单点汇接在配电端子排，**不要**把舵机 GND 串在主控 GND 之后。

### 线束表

| 编号 | 起点 | 终点 | 线规 | 长度 | 连接器 | 备注 |
|---|---|---|---|---|---|---|
| W1 | 12V 适配器 | DC 座 | 18 AWG | 1.0 m | DC 5.5×2.1 | 带磁环更好 |
| W2 | DC 座 | 配电板 V+/GND | 18 AWG | 0.3 m | 焊接/端子 | 串 SS34 |
| W3 | 配电板 V+/GND | 主控降压模块 | 22 AWG | 0.2 m | 端子 | 12V 侧 |
| W4 | 降压模块 5V | ESP32 5V/GND | 22 AWG | 0.2 m | USB 线或端子 | 别走 USB 口取电 |
| W5–W8 | 配电板支路 | 舵机 1–4 | 舵机原厂线 | 0.15 m | PH2.0-3P | 支路串 2A 保险 |
| W9 | 主控收发器 DATA | 舵机1 DATA | 24 AWG | 0.3 m | PH2.0-3P | 双绞更好 |
| W10–W11 | 舵机 n DATA | 舵机 n+1 DATA | 24 AWG | 0.2 m | PH2.0-3P | 菊花链 |

> 采购时**多买 2 根 PH2.0-3P 公对公线**：改线序、延长链路都要用，单买运费比线贵。

## 3.5 急停与保险（硬件安全底线）

```
电池 + ──[ 5A 保险 ]──[ 急停按钮 NC ]──┬── 总线舵机 12V
                                       └── DC-DC 5V ── 树莓派/ESP32
电池 - ────────────────────────────────┴── GND（单点共地）
```

三条硬规则：

1. **常闭（NC）**：正常导通，按下断开。用常开的话，线松了 = 急停失效且你看不出来。
2. **断正极，不断负极**：断负极时，若还有别的接地路径（USB 调试线），电流会绕过去。
3. **按钮位置**：底盘后部、一只手能拍到；不要放在夹爪运动范围内。

验证方法（**每次改线后做一次**）：上电 → 舵机使能 → 拍下急停 → 用手推轮子应能自由转动，
示波器/万用表量舵机 12V 应为 0V。不复位按钮，上位机不应能重新使能。

## 4. 软件限流（比换大电源便宜）

三个寄存器就能把峰值电流压到 5A 以内：

| 寄存器 | 地址 | 建议值 | 作用 |
|---|---|---|---|
| 转矩限制 | 0x30 | 600（=60%） | 直接把输出扭矩封顶，堵转电流随之下降 |
| 保护电流 | 0x1C | 384（=2.5A） | 超过即过流保护 |
| 加速度 | 0x29 | 30 | 限制加速度，抑制启动冲击电流（0 = 最大加速度，禁用） |

配合固件里的"最多同时动 2 个关节"策略，5A 电源也能安全跑。

## 5. ID 分配与拓扑

| ID | 角色 | 零位来源 | 限位（软） |
|---|---|---|---|
| 1 | 底座偏转（yaw） | 装配后标定 | −120°…+120° |
| 2 | 肩（pitch） | 装配后标定 | −90°…+60° |
| 3 | 肘（pitch） | 装配后标定 | 0°…+135° |
| 4 | 夹爪 / 车轮 | 按构型 | 按构型 |

**改 ID 的安全流程**（唯一允许广播的场合）：

```
1. 总线上只接这一只舵机（否则会把别人的 ID 也改掉）
2. 写 0x37 = 0   （解锁 EEPROM）
3. 广播写 0x05 = 新ID（ID=0xFE）
4. 读回 0x05 确认
5. 写 0x37 = 1   （上锁，掉电保存）
```

## 6. 常见故障 → 电气原因对照

| 现象 | 最可能的电气原因 |
|---|---|
| 扫描不到任何 ID | 12V 没上；DATA 与 V+ 接反；主控 TX/RX 没交叉；收发器方向脚没电 |
| 扫到几个、其余超时 | 菊花链中间一根线松；某舵机 ID 重复 |
| 一动就复位 | 电源功率不足；没加 1000µF；主控与舵机共地不良 |
| 位置抖动 ±3 计数 | 波特率不对（1M 用 115200 配置）；线太长无上拉 |
| 读回电压 < 9V | 线径太细（见 §2）；某处接触电阻大 |
