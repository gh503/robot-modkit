# 15 · 生产链路总览

> 这份文档回答一个问题：**"照这个仓库，能不能把机器人真的造出来？"**
> 每一环都写清楚：输入是什么、用什么命令、输出是什么、谁验收。
> 状态用 `✅ 可用` / `🟡 进行中` / `⬜ 未开始` 标记，随迭代更新。

## 0. 一条链路，八个环节

```
设计冻结 → 工艺文件 → 采购 → 加工 → 装配 → 标定 → 测试 → 批次/迭代
   ✅        🟡       ✅     ✅      ✅      🟡      🟡       ⬜
```

"支持"的标准不是"有文档"，而是**两个不同的人，照同一份东西，能做出同样的结果**。
所以每一环都尽量做到：参数单一真源（`cad/params.py`）、可执行检查（脚本退出码）、
可复现的记录（JSON/表格），而不是"看图说话"。

### 1.4 加工 ✅（FDM 路线）

- 13 个零件 + 校准件 + 3 张拼盘，全部 ≤ 220 床；拼盘利用率 63%
- 单套 351 g / 13.9 h（15% 填充 + 4 壁）
- 校准件必须先打：槽宽 24.7/25.1/25.5 三档，选能塞进舵机又不晃的那档

**门禁**：校准件通过 → 再打正式件（避免 13 小时后发现孔小了 0.3mm）。

### 1.5 装配 ✅

- [`docs/05-装配手册.md`](05-装配手册.md)：分 6 步，每步有"做完应该看到什么"
- 紧固件表在 [`docs/11-零件清单.md`](11-零件清单.md)
- 常见装反/装错在 [`docs/09-故障排查.md`](09-故障排查.md)

**门禁**：手动转动每个关节，无卡滞；四个轮子同时着地（晃动量 < 1mm）。
