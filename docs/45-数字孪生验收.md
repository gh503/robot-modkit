## 2. 仿真抓到并修掉的真问题

1. **速度寄存器口径差 11.4 倍**：固件 tick/s vs 上位机 deg/s → 统一为 deg/s per LSB。
2. **计数回绕假倒退**：固件跨 0 时速度环反向、里程计跳 200mm → 12 位最短路径。
3. **丢帧直接崩**：没有重试 → `RetryLink`，5% 丢帧可恢复。
4. **打滑毁掉纯里程计**：>70mm → 固定相机标记定位，回到 5–9mm。
5. **透视偏差**：40mm 方块顶面直接用 z=0 标定偏 10mm → `table_calib(z_obj)`。

## 4. 结论

**采购前的软件调试目标已达成**：可以在没有一台实物的情况下，用 16 个场景回归导航、视觉、
任务、固件、总线、电源、打滑与定位，并生成调试图；v1.4 另加了运动安全联锁。

但物理闸门仍是 **0/5**：docs/42 §3 的 11 步只能在硬件到位后做。仿真通过 ≠ 实物通过。
