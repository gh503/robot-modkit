## 4. 加工步骤

1. 按裁线表裁线（每根留 10mm 余量，压接后再修剪）；
2. 剥线 3mm，**不要伤到铜丝**（断股会让 12V 回路发热）；
3. 压接端子后拉一下（≥30N 不脱）；
4. 两端套热缩管 + 编号标签（`W8` 这种），标签朝同一方向；
5. 万用表通断档逐根测：两端导通、相邻两线不短路；
6. 上电前再测一次 12V 与 GND 是否短路（蜂鸣档不应响）。
