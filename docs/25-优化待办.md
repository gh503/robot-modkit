## 3. 第 1 项的具体改法

`cad/params.py`：

```python
M3_CLR = 3.4          # 现在
M3_CLR_FIT = 3.6      # 新增：需要容错的对接孔（底盘/连接板）
```

然后在 `parts_m1.chassis_*` 与 `chassis_joiner` 的对接孔用 3.6，其余仍 3.4。
重跑 `build.py`（85 项）→ `drawings.py` → `cost.py`，确认无干涉、图纸孔表更新。

## 4. 第 2 项的具体改法

固件读电压寄存器（`0x3A`），1 秒滑动平均 < 10.5V 时：

- 蜂鸣/闪灯（有则用）；
- 速度上限降到 50%；
- 连续 10 秒仍低 → 卸力并拒绝新指令（保留急停）。

测试：仿真电压从 12.0 降到 10.0，断言进入降级；回到 11.5 恢复。
