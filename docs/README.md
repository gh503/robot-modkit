| 类型 | 回答什么问题 | 文档 |
|---|---|---|
| **教程**（Tutorial） | "带我走一遍，能成" | [07 小白手册](07-小白操作手册.md) |
| **操作**（How-to） | "我要做 X，怎么做" | [05 装配](05-装配手册.md)、[06 调试](06-调试与测试.md)、[09 故障排查](09-故障排查.md)、[12 仿真](12-仿真与可视化.md)、[15 生产链路](15-生产链路总览.md) |
