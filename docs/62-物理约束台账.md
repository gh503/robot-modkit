# 物理约束台账

> 目标：把“机器人能不能动、会不会撞、会不会烧、坏了能不能修”拆成可检查的条目，
> 每条都写清**现在怎么处理、证据是什么、还缺什么**。这不是“全量物理证明”，
> 而是一张诚实的地图：绿色不代表已经过实物验证。

## 0. 怎么读

| 标记 | 含义 | 能作为什么 |
|---|---|---|
| ✅ 已核算 | 有静力/几何/电气计算或 CAD 校核 | 设计冻结的依据，不是实物证据 |
| ✅ 已仿真 | `HardwareSim`/接触/公差等模型跑过 | 趋势和边界，参数仍是估计值 |
| ✅ 已联锁 | 代码在动作前会拒绝 | 能降低误操作，不是安全认证 |
| ◐ 部分 | 只覆盖了理想化/静态/单一工况 | 不能外推到真实工况 |
| ○ 仅流程 | 只有文档、检查表或人工确认 | 依赖操作者，不是自动保护 |
| ✗ 未覆盖 | 没有模型、测试或联锁 | 到货后必须补 |

**关键结论（v1.4.0）**：设计冻结级检查可以离线复现；物理验收仍是 **0/5**。
没有购买、打印、装配、电气测量、固件上板、标定和 M1–M5 实测。

## 9. v1.4.0 真正接入的联锁边界

### 9.1 Python 侧

```text
SafetyPolicy
  ├─ check_target      关节范围 + 单步跳变
  ├─ check_health      在线/温度/电压/故障位/反馈新鲜度
  ├─ preflight         全轴预检（可扫描 + 期望 ID）
  ├─ apply_limits      写 0x30 转矩 / 0x1C 电流 / 0x29 加速度
  └─ guard_motion      以上全部通过才返回 ok

Robot
  ├─ goto_checked
  ├─ sync_goto_checked
  └─ move_pose_checked  逆解 + 几何包络 + 联锁
```

- 越界、超温、低压、故障、反馈过期、单步过大 → `ValueError`，**不发运动帧**。
- `preflight` 失败返回码 2；`--write-limits` 只在通过时写。
- 默认限位来自设计；`--calibration` 用标定文件覆盖零位/方向/限位。

### 9.2 查看器侧

- `scene.js` 带 `safety` 块；`guardMotion()` 在下发前检查：
  4 轴反馈新鲜度、温度、电压、故障位、目标软限位、单步、几何包络。
- 通过后才写 0x30/0x1C/0x29，再发 0x2A；速度默认 300。
- 可载入 `calibration.json` 覆盖零位/方向/限位/ID。
- 3D HUD 对桌面/底座/折叠做即时提示；提示不等于联锁，真正拒绝在下发路径。

### 9.3 明确没做的事

- 没有动态碰撞检测、没有力矩传感、没有安全 PLC/安全继电器。
- 没有实测定标、温升、堵转、摩擦、回差、电池曲线。
- 没有功能安全认证；**不能用于人身安全相关场景**。
- UI 的“我已确认”只是交互确认，不是安全功能。

## 10. 到货后的优先顺序

| 顺序 | 先补什么 | 为什么 | 对应验收 |
|---|---|---|---|
| 1 | G0 尺寸/质量/电压 + 只读扫描 | 所有模型都依赖真实参数 | [28](28-生产就绪检查.md) G0/G1 |
| 2 | 单轴低速、限位、急停 | 先保证“能安全停下来” | [63](63-硬件到货执行单.md) D6–D7 |
| 3 | 标定零位/方向/限位 | 没有标定，软限位是错的 | `calib` + `preflight --calibration` |
| 4 | 回差/重复精度/温升 | 决定能否做抓取和长时运行 | `backlash`、`bench` |
| 5 | 电池 sag/低压保护/堵转 | 决定电流与保险是否够 | 配电实测 |
| 6 | 抓取 μ/夹持力/滑移 | 决定抓取参数是否可信 | 接触实验 |
| 7 | 碰撞/跌落/寿命 | 决定能不能长期用 | 破坏性/寿命测试 |

## 11. 诚实结论

- **能离线做的，已经尽量做成了代码、测试和拒绝路径**：软限位、单步、温度/电压/故障、
  转矩/电流/加速度、桌面/底座/折叠几何、标定覆盖、预检 CLI、查看器联锁。
- **不能离线替代的，仍然没有做**：实物标定、真实温升、堵转/摩擦/回差、动态碰撞、
  功能安全、寿命与维修。把它们写成“已通过”是不诚实的。
- 物理闸门 **0/5** 不变。下一步不是继续加 UI，而是按
  [63 硬件到货执行单](63-硬件到货执行单.md) 做一次真实的 bring-up。
