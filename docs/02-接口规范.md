# 01 · 接口规范 v0.1

> 这份文件是**全项目的契约**。零件、固件、采购都以它为准；改它要写变更记录。
> 上一轮口头说的"PH2.0 四针"是错的：**飞特总线舵机是 3 线半双工**（GND / V+ / DATA），本文件已更正。

---

## 1. 机械接口

| 项目 | 规定 | 理由 |
|---|---|---|
| 唯一螺钉 | M3×8 / M3×10 / M3×12，内六角圆柱头，不锈钢 | 全机一把 2.5mm 内六角就能拆完 |
| 连接面网格 | 20mm 间距，孔径 Ø3.4 | 孔距是 20 的整数倍 → 任意两块板可任意位置对接 |
| 对接方式 | 平面贴合 + 螺栓穿过两层（+ 螺母或热熔铜螺母） | 不允许"打印卡扣"做主要承力 |
| 板厚 | 主结构 4mm，盖板 3mm | 4mm 板配 4 层壁即可承受关节扭矩 |
| 热熔铜螺母 | M3×5×4，底孔 Ø4.2 × 6 深 | 反复拆装不滑牙（自攻螺纹第三次就废） |
| 最小壁厚 | 1.2mm | FDM 0.4 喷嘴可稳定成形 |
| 圆角 | 外角 ≥ R2（可选，未做强约束） | 减少磕碰缺口 |
| 舵机固定 | 浅槽限位（单边 0.2mm）+ 盖板压住（间隙 0.4mm） | 不依赖未知的舵机安装孔位 |

### 关节模块的坐标与堆叠（打印件必须遵守）

```
z = +40.0  ┬  输出盘法兰顶面（接下一节 / 轮毂）
z = +36.0  ┤  输出盘法兰底面   ← 与盖板留 0.6mm 轴向间隙（旋转件不蹭固定件）
z = +35.4  ┤  盖板顶面（固定面，带 20mm 网格）
z = +32.4  ┤  盖板底面
z = +32.0  ┤  舵机顶面（花键从这里长出 2.0mm）
z = 0.0    ┤  底板上表面 = 原点平面
z = -2.4   ┤  舵机浅槽底（舵机坐在这里）
z = -4.0   ┴  底板下表面（带 20mm 网格，接上一节）
```

**两个标准连接面**：底板下表面（固定侧）与输出盘法兰顶面（旋转侧）。
任何连杆/轮毂只要遵守 20mm 网格 + Ø3.4，就能装到这两个面上 —— 这就是"结构变换"的全部机制。

## 2. 电气接口

### 2.1 总线

| 项目 | 规定 |
|---|---|
| 电平 | TTL 单端，信号高 2–5V（ESP32 3.3V 直接兼容） |
| 拓扑 | 菊花链（daisy-chain），不允许多分支星形 |
| 线序 | 3 芯：**GND / V+ / DATA**（飞特出厂线序，插头防呆） |
| 连接器 | PH2.0-3P（舵机端原厂自带 15cm 线，另一头按需压接） |
| 波特率 | 出厂默认 **1 Mbps**（内存表 0x06 = 0），本设计沿用 1 Mbps |
| 协议 | FT-SCS 自定义协议（`FF FF ID LEN INSTR PARAMS CHK`） |
| ID | 0–253，254 为广播；**全机唯一** |
| 终端电阻 | 总线 < 1m 时不加；> 2m 时在末端 DATA 与 V+ 之间加 1kΩ 上拉 |

### 2.2 供电

| 项目 | 规定 |
|---|---|
| 额定电压 | 12V（型号范围 9–12.6V；官方表 4–14V 与 PDF 不一致，按 12V 使用） |
| 台面电源 | 12V / 5A 适配器（起步）；4 舵机同时堵转需 10.8A，见 `docs/02` |
| 主控供电 | 从 12V 经降压模块到 5V（ESP32 开发板 USB 口不进 12V） |
| 保险 | 每舵机支路 2A 自恢复保险丝；总回路 8A |
| 接地 | 单点：所有 GND 汇到配电板一点，避免地环流进信号线 |
| 反接保护 | 电源入口串 SS34 肖特基（0.4V 压降可接受）或 P-MOS 理想二极管 |

### 2.3 上电顺序（必须遵守）

1. 12V 主电源 → 2. 等 200ms 让舵机自检 → 3. 主控上电/复位 → 4. 扫描 ID → 5. 使能扭矩。

> 反过来的典型症状：主控先跑起来扫描，舵机还没上电 → 扫到 0 个 ID，误判"全烧了"。

## 3. 身份接口（换了能被认出来）

| 规则 | 内容 |
|---|---|
| ID 分配 | 按关节链顺序 1、2、3、4…；模块外壳上**贴标签**（打印件留 8×12mm 铭牌位待加） |
| 角色表 | ID → 角色由固件配置表决定，不写死在机械里 |
| 自动枚举 | 上电 `scan(0..20)`，用 `PING` 逐个探（**不能广播 PING**，多机会撞总线） |
| 热插拔 | 支持断电插拔；带电插拔只允许在扭矩关闭（0x28=0）时进行 |
| 换件流程 | 换新舵机 → 改 ID（0x05，改完写 0x37=1 上锁保存）→ 与配置表比对 → 通过才使能 |

## 4. 软件接口

### 4.1 帧格式（已实现并测试）

```
FF FF | ID | LEN | INSTR | PARAM... | CHK
LEN = 参数字节数 + 2
CHK = ~(ID + LEN + INSTR + ΣPARAM) & 0xFF
```

### 4.2 关键寄存器（STS 系列，低字节在前）

| 用途 | 地址 | 长度 | 说明 |
|---|---|---|---|
| 工作模式 | 0x21 | 1 | 0=位置伺服，1=恒速（轮子用），见 §6 |
| 目标位置 | 0x2A | 2 | 0–4095，BIT15 为方向位 |
| 运行时间 | 0x2C | 2 | 0 = 不限时 |
| 运行速度 | 0x2E | 2 | 0 = 最高速 |
| 加速度 | 0x29 | 1 | 0–254；`SafetyPolicy.acc` 默认 30 |
| 扭矩开关 | 0x28 | 1 | 0 卸力 / 1 出力 / 2 阻尼 / 128 中位校准 |
| 电流限制 | 0x1C | 2 | 默认 384（384×6.5mA ≈ 2.5A） |
| 转矩限制 | 0x30 | 2 | 默认 600（约 60% 额定） |
| 当前位置 | 0x38 | 2 | 只读 |
| 当前速度 | 0x3A | 2 | |
| 当前负载 | 0x3C | 2 | |
| 当前电压 | 0x3E | 1 | 0.1V |
| 当前温度 | 0x3F | 1 | ℃ |
| 舵机状态 | 0x41 | 1 | 位域：电压/磁编码/温度/电流/负载 |
| ID | 0x05 | 1 | 改完要写 0x37=1 上锁 |
| 波特率 | 0x06 | 1 | 0=1M, 1=500k, 2=250k, 3=128k, **4=115200** |

### 4.2.1 安全寄存器默认值

`software/modkit/safety.py` 的默认策略在运动前写：

```text
0x30 = 600   转矩限制（约 60%）
0x1C = 384   电流限制
0x29 = 30    加速度
0x2E = 300   速度（目标帧里给）
```

越界/超温/低压/故障/反馈过期由 `preflight` 与 `guard_motion` 拒绝；
详见 [62 物理约束台账](62-物理约束台账.md)。**写入成功 ≠ 舵机一定支持**，首次上真机要单轴确认。

### 4.3 角度约定

- 4096 计数 = 360°，1 计数 = 0.0879°
- 固件里统一用 `degToTicks()` / `ticksToDeg()`，禁止在业务代码里手写 `/4096*360`
- 装配后每个关节要**单独标定零位**（写入 0x28=128 把当前位置设为 2048）

### 4.4 模块化固件的分层

```
业务（构型动作序列）
   ↓
关节抽象（Joint：限位、零点、方向、减速比）
   ↓
驱动（ScsBus：ping / read / write / syncWrite / syncRead）
   ↓
HAL（IHalfDuplexBus：方向切换、微秒超时、flush）
   ↓
平台（ESP32 单线半双工 / PC 假总线）
```

下层可替换、可测试，上层只依赖抽象 —— 换主控（ESP32 → STM32 → 树莓派）不动业务代码。

## 6. M1 扩展：底盘与夹爪

### 6.1 底盘

| 项目 | 规定 | 理由 |
|---|---|---|
| 底盘板 | 240 × 200 × 5mm，20mm 网格 | 与关节模块同一套孔 |
| 驱动轮 | Ø65mm 橡胶轮，轮距 150mm | 65mm 轮 + 30kg·cm 舵机 → 单轮推力约 9kg |
| 支撑 | 2× 万向球轮（前/后各一） | 三点/四点支撑，转向不打滑 |
| 驱动方式 | 舵机**恒速模式**（0x21=1），速度写 0x2E | 同一批舵机当电机用，不需要额外编码器 |
| 舵机固定 | 打印支架（drive_bracket）托盘承重 + 两侧腿限位 | 不依赖官方安装孔坐标 |
| 速度单位 | `DriveConfig::speed_unit`，**必须实测标定** | 各型号 LSB 含义不同，猜必错 |
| 速度方向 | 0x2E 的 BIT15 为方向位 | 写 1024 = 正转，写 1024\|0x8000 = 反转 |
| 离地间隙 | ≥ 15mm | 过门槛/地毯 |

**差速运动学**（已实现于 `software/modkit/kinematics.py`）：

```
v_L = v − ω·b/2 ,  v_R = v + ω·b/2      （b = 150mm）
里程计: ds = (s_R + s_L)/2 ,  dθ = (s_R − s_L)/b
```

### 6.2 夹爪

| 项目 | 规定 |
|---|---|
| 驱动 | 1 个舵机（ID 4），位置控制 |
| 开口 | 0–40mm（对应舵机 180°→120°） |
| 指尖 | 可更换打印件（V 形 / 平面 / 软胶） |
| 夹持力 | 受 0x30 转矩限制约束，默认 60% |
| 反馈判据 | 夹住时负载上升且位置停住 → 用 `load` + `position` 双判据，不要只看位置 |

### 6.3 ID 总表（M1 定稿）

| ID | 角色 | 模式 |
|---|---|---|
| 1 | 底座偏航 | 位置 |
| 2 | 肩 | 位置 |
| 3 | 肘 | 位置 |
| 4 | 夹爪 | 位置 |
| 5 | 左驱动轮 | 恒速 |
| 6 | 右驱动轮 | 恒速 |

> 6 个舵机一条链。**驱动轮和关节是同一种零件** —— 这就是模块化最硬的证据。

### 6.4 与上位机的通信（树莓派 ⇄ ESP32，M2 起）

| 项 | 约定 |
|---|---|
| 物理层 | USB 串口，115200 8N1 |
| 帧 | `AA 55 | LEN | CMD | PAYLOAD | CRC8`（自定，非舵机协议） |
| 心跳 | 上位机每 100ms 发一次；ESP32 200ms 收不到 → 全部卸力 |
| 急停 | CMD=0x0F，立即卸力并回 ACK |
