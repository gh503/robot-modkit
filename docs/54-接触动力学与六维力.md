# 54 · 接触动力学与六维力

> 47 只回答"夹不夹得住"；这篇回答"滑了多少、什么时候掉、腕部受力多大"。
> 仍然是集总参数模型，不是有限元，也不做方块转动。

## 1. 模型

夹爪沿 ±X 夹紧，重力沿 −Z。切向负载：

```
L = m·√(ay² + (g+az)²)
```

- 静摩擦上限 `2·μs·N`；
- 动摩擦上限 `2·μk·N`，默认 `μk=0.8·μs`；
- 未超限：切向弹簧 `slip = L/k`（k=40N/mm），不累积；
- 超限：相对加速度 `(L − 2μk·N)/m`，速度/位移累积；
- 滑移 ≥18mm（方块半长 20mm）→ `dropped`。

## 2. 六维力

腕部感受到的支撑力与力矩：

```
F = m·(ax, ay, g+az)
r = (0, 0, −30mm)      # 方块质心在腕点下方
M = r × F
```

输出 `fx/fy/fz/tx/ty/tz`，单位 N / N·m。`Wrench.force_n` 与 `torque_nm` 给模长。

## 3. 场景键

```json
{"cmd":"mission", ..., "mu":0.4,
 "transport_accel":80, "transport_seconds":0.5,
 "slip_limit":18}
```

- `transport_accel`：运输时注入的横向加速度（m/s²）；
- 抓取后按 10ms 步进积分，超摩擦锥就滑；
- 断言可用 `contact.state / slip_mm / dropped / wrench.fz`。

## 4. 结果

| 场景 | 条件 | 结果 |
|---|---|---|
| `fast_transport` | μ=0.4，a=80m/s² | 滑移 18mm 掉落，期望失败 |
| 默认 mission | 无运输加速度 | 保持，滑移 0.01mm |
| 低 μ=0.05 | 静止 | 2μN=0.4N < 0.49N，掉落 |

六维力示例（50g 方块静止）：`fz=0.4905N`，`tx=0`；80m/s² 加速时
`fy=4.0N`、`tx=0.12N·m`。

## 5. 边界

- 没有方块转动/翻滚，没有接触面压力分布；
- 柔性是单自由度弹簧，不是粘弹性/迟滞；
- μs/μk/刚度都要真机标定；当前值来自橡胶-PLA 估算；
- 六维力是"模型算出来的腕部等效力"，不是仿真出来的应变片噪声；
- 运输加速度是场景注入，不是从轨迹反推的（后续可接 nav 加速度）。
