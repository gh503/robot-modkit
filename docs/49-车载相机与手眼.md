# 49 · 车载相机与手眼

> 固定俯视相机是"实验室上帝视角"；真机上相机装在车上，随机身一起转。
> v0.8.4 起相机可以跟随机身，检测结果直接换到臂基座坐标。

## 1. 模型

`Camera` 增加 `yaw_deg`，投影/反投影做一次旋转：

```
local = R(-yaw) · (world − camera)
u = cx + fx · local_x / (z − Z)
```

`table_calib(z_obj)` 也带上旋转，像素 → 桌面坐标仍是仿射矩阵，视觉代码不用改。

## 2. 场景

```json
{"cmd":"mission", "pick":[200,0], "drop":[-150,0],
 "nav":true, "camera":"onboard", "standoff":150,
 "camera_z":500, "fx":250, "cam_w":320, "cam_h":240}
```

- `camera:"onboard"`：每次 `look()` 把相机放到当前底盘位姿；
- `standoff:150`：导航停在方块前 150mm，否则相机正对方块、臂基座坐标接近 0，
  逆解会顶到肘关节极限（真实机器人也一样，得留观察距离）；
- 检测到世界坐标后，用底盘位姿转到臂基座，再逆解抓取。

运行：

```bash
modkit simrun --scenario sim/scenarios/mission_onboard.json
# mission True 13.3s 完成
```

## 3. 验证

- 相机 yaw 投影/反投影往返误差 <0.01mm；
- 40° 旋转下渲染 → 检测 → 桌面坐标误差 <8mm；
- 车载场景 11/11 通过（导航 → 看 → 抓 → 搬）。

## 4. 边界

- 仍是垂直向下、无镜头畸变、无安装倾角；
- 没有手眼标定误差（相机外参是"真值"）；真机要标 `T_base_cam`；
- 没有遮挡/运动模糊/自动曝光；
- `standoff` 是手工给的，后续应由视野和臂可达工作空间共同决定。
