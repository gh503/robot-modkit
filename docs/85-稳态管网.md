# 85 · 稳态管网：节点、管段、泵、需求

> 状态：**v1.38.1 已实现**，软件/测试可运行；无实物验证，物理闸门 **0/5**。
> 定位：泳池循环、灌溉、冷却液等“泵—管—阀—过滤器”的方案比较；
> **不是**瞬态水锤、气蚀、多相流或 CFD。

## 85.1 为什么需要它

原来的单管 `pipe_drop` 只能算“一根管、给定流量”的压降。真实系统里：

- 泵的工作点由**泵曲线 + 管路阻力**共同决定，不是固定流量；
- 多根管并联会分流，环网会回流；
- 过滤器/阀门的局部损失会改变工作点；
- 定水头水箱/水池会影响全系统压力。

管网求解器把这些问题放在一个小型、可解释的稳态模型里。

## 85.2 schema（`modkit.network/1`）

```json
{
  "schema": "modkit.network/1",
  "name": "泳池循环",
  "fluid": "water",
  "nodes": [
    {"id": "pool", "elevation_m": 0.0, "head_m": 1.2, "kind": "tank"},
    {"id": "pump_in", "elevation_m": 0.0},
    {"id": "filter_in", "elevation_m": 0.3},
    {"id": "pool_return", "elevation_m": 1.1}
  ],
  "pipes": [
    {"id": "suction", "from_node": "pool", "to_node": "pump_in",
     "length_m": 2.0, "diameter_m": 0.05, "minor_k": 2.0},
    {"id": "filter", "from_node": "filter_in", "to_node": "pool_return",
     "length_m": 1.0, "diameter_m": 0.05, "minor_k": 8.0},
    {"id": "return", "from_node": "pool_return", "to_node": "pool",
     "length_m": 2.0, "diameter_m": 0.05, "minor_k": 1.0}
  ],
  "pumps": [
    {"id": "pump", "from_node": "pump_in", "to_node": "filter_in",
     "efficiency": 0.55,
     "curve": [[0.0, 12.0], [0.0005, 10.0], [0.0010, 7.5],
               [0.0015, 4.0], [0.0020, 0.0]]}
  ]
}
```

- **定水头节点**：`head_m` 非空（水池/水箱/市政入口）；至少一个。
- **需求节点**：`demand_m3_s` 是抽出流量（正数）；未知节点水头由求解器算。
- **管段**：Darcy-Weisbach 沿程 + `minor_k` 局部损失；`status=closed` 可临时关断。
- **泵**：`curve` 为 `[Q, H]` 点，线性插值；`speed` 用相似定律
  `Q'=Q/speed`、`H'=H(Q')×speed²`；`efficiency` 只用于轴功率。
- **流体**：`water` 或材料库其它 key；密度/粘度影响 Re 和损失。

单位：m、m³/s、m 水头、Pa/kPa、W。

## 85.3 求解方法

未知量：每个未知节点水头 + 每条边流量。

方程：

```text
对每根管：h_from - h_to - h_loss(Q) = 0
对每台泵：h_from - h_to + H_pump(Q) = 0
对每个未知节点：ΣQ_in - ΣQ_out - demand = 0
```

- `h_loss = (f L/D + K) · v|v| / (2g)`，`v=Q/A`；
- `f` 由 Re 与相对粗糙度计算（层流 64/Re；湍流 Swamee-Jain 近似，
  与 `fluid.pipe_drop` 共用 `_friction_factor`）；
- 阻尼 Newton + 数值 Jacobian + 回溯线搜索；
- 连续性残差 ×1000 做尺度归一；默认 `max_iter=60`，`tol=1e-9`；
- 泵工作点超出曲线端点时 clamp，并在 `warnings` 里标出；
- 不收敛/奇异会报错，不返回“看起来像结果”的假数据。

## 85.6 验证与判据

测试覆盖：

- 单管需求 → 流量等于需求、节点压力下降；
- 并联对称 → 流量均分；
- 泵曲线 → 已知曲线下流量/扬程/轴功率；
- 环网 → 收敛、质量守恒；
- 非法拓扑（缺定水头、自环、重复 id、悬空节点）被拒绝；
- 泵相似定律；
- CLI validate/solve/输出文件。

**现场判据**（未做）：

- 用钳形功率计/流量计测泵工作点，与曲线对比；
- 测过滤器前后压差，反推 `minor_k`；
- 至少 3 个工况（阀开度/滤芯新旧）验证；
- 达不到 ±15% 就只用于方案比较，不写“已验证”。

## 85.7 边界

- 稳态：没有水锤、瞬态启停、气蚀、空化、多相；
- 泵曲线必须来自厂家/实测；没有曲线不能编；
- 局部损失 K、粗糙度、需求流量都是输入假设；
- 不包含 controller/变频器动态、电机效率地图、过滤器堵塞时间演化；
- 不是施工图、选型保证或安全认证；物理闸门 **0/5**。
