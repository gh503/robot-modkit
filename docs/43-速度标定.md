# 43 · 速度寄存器标定（M2 上车第一件事）

> `0x2E` 写 500 到底转多快？不同批次、电压、负载都不一样。
> 不标定就闭环，等于蒙眼开车。docs/06 的 G7 就是这条。

## 1. 方法

1. 轮子**离地**，12V 供电；
2. `0x21=1` 切恒速模式，开扭矩；
3. `0x2E` 写一个已知 LSB（默认 500）；
4. 每 50ms 读一次位置计数（0x38），用 `tick_delta` 累计，避免过零跳变；
5. 平均角速度 = 累计角度 ÷ 时间；
6. `speed_unit = 实测 deg/s ÷ 写入 LSB`。

## 2. 命令

```bash
modkit --sim speedcal --sid 5 --lsb 100 --seconds 0.5
modkit --port /dev/ttyUSB0 speedcal --sid 5 --lsb 500 --save speed.json
```

输出：

```json
{
  "sid": 5,
  "lsb": 500,
  "seconds": 1.0,
  "deg_s": 500.2,
  "unit": 1.0004,
  "ticks": 5688,
  "ok": true,
  "note": ""
}
```

`--save` 只在 `ok` 时写 `{"speed_unit": ..., "wheel_sid": ...}`。

## 3. 仿真与实测

| 项 | 结果 |
|---|---|
| 仿真 LSB 100 / 0.5s | 100.02 deg/s，unit 1.0002 |
| 仿真 LSB 500 / 1s | 500.2 deg/s，unit 1.0004 |
| 轮子不动 | `ok=false`，提示检查模式/扭矩/电源 |
| 转向相反 | `ok=false`，提示换线或方向位取反 |
| LSB=0 | 抛 `ValueError` |

4 项测试，`tests/test_speedcal.py`。

## 4. 怎么用这个数

```python
from modkit.robot import Robot
bot = Robot(link, speed_unit=1.0004)
left, right = bot.drive_speed(100, 0)   # 内部按 speed_unit 换算 LSB
```

固件侧 `DriveConfig::speed_unit` 与这里**同一口径**（deg/s per LSB）；固件
`mmToRegister` 先算 `deg/s = mm/s × 360 / 周长`，再除以 `speed_unit`。**仿真里的 1.0 是占位**，
真机必须按上面步骤实测后写回配置。

## 5. 注意

- 空载标定和落地负载会有差异；有编码器时可以用位置闭环兜底，但速度前馈仍建议空载+负载各测一次；
- 电压从 12.6V 掉到 11V 时转速会降，长时间任务建议定期重标；
- 左右轮分别标（`--sid 5` / `--sid 6`），不要假设对称；
- 方向位（BIT15）与接线方向要一起确认，否则闭环会正反馈。
