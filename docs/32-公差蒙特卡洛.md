2. **闭环**：编码器在舵机内部，末端闭环需要外部视觉/标定（M3）；

4. **换舵机**：金属齿轮 + 更小回差（¥95→¥180/只），最后才考虑。

- 力臂按单轴叠加，没做完整 DH 变换（保守估计）。
