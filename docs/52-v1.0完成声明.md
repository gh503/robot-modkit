## 2. 一条命令验证

```bash
make check        # CAD + 固件 + 上位机 + 场景 + 文档（首次约 5–8 分钟）
make check-fast   # 跳过 CAD，约 30 秒
```

`make check` 的每一步都是 CI 里的同一条命令，没有"本地能过、CI 不过"的分叉。
