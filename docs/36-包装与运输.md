# 36 · 包装与运输

> 机器装好了，坏在快递路上等于白做。这一篇定：**怎么折、怎么装、怎么摔得起**。

## 1. 发货姿态（必须按这个折）

| 部位 | 姿态 | 为什么 |
|---|---|---|
| 偏航 | 0°（朝正前） | 减少横向包络 |
| 肩 | 0°（水平） | 重心靠近底盘 |
| 肘 | -90°（垂直向下） | 降低总高 |
| 夹爪 | 闭合到 0.3（留 3mm 缝） | 避免夹爪受力 |
| 轮子 | 用扎带或泡沫块固定 | 防止运输中滚动带动舵机 |

> 折好后整机包络约 **300×240×220mm**（含夹爪），以实测为准。

## 3. 配件盒清单

- [ ] M3×8/10/12 各 4 颗（备用）
- [ ] 5A 保险丝 ×2

- [ ] 电池（如含）：单独绝缘袋，**电量 30–50%**，外箱贴 UN3481 锂电池标

## 4. 跌落与振动

出厂抽检（每批 1 箱）：

| 项 | 方法 | 判据 |
|---|---|---|
| 跌落 | 1.2m，6 面各 1 次（水泥地） | 开箱后 `selftest` 六轴全过、外壳无裂 |
| 振动 | 振动台 10–55Hz，2h（无条件可省） | 螺丝无松动、线束无磨破 |
| 堆码 | 箱上压 10kg，24h | 箱体不塌、内部无压痕 |

不合格 → 加厚泡沫或改内衬，不要"下次注意"。

## 5. 运输标识

- 正面：`↑↑` 向上、`易碎`、`防潮`
- 侧面：序列号 + 二维码（指向该台的 `records/<serial>.json` 摘要页）
- 电池标：UN3481（如含电池）
- 不要写"精密仪器"以外无意义的话，快递只看图标
