# 61 · v1.3 产品级 UI/UX 优化

> v1.3 不加机器人能力，只把两个界面从"能用的调试页"改成"新手敢点、老手高效"的产品：
> 仿真工作台（深色）与在线 3D 查看器（浅色）。所有交互都在浏览器里可复现，不依赖硬件。

## 1. 目标与边界

| 目标 | 做法 | 不做什么 |
|---|---|---|
| 第一次打开知道先点哪 | 查看器加一句主行动 + 提示条；工作台默认选 `mission_pick.json`，空状态写清下一步 | 不做多步新手向导 |
| 状态永远可见 | 顶栏运行状态、时钟、连接状态；断线横幅 + 重试 | 不弹阻塞式错误框 |
| 危险动作先确认 | 真机"使能扭矩/下发姿态"首次弹安全确认；急停始终在视图上 | 不代替硬件急停 |
| 键盘高效 | 空格、→、R、L、F、?、1–4；标签页方向键 | 不做可配置键位 |
| 小屏可用 | 工作台单视图切换；查看器舞台 54vh + 参数下移；44px 级触控目标 | 不做独立 App |
| 可访问 | `aria-selected`/`aria-live`/`aria-label`、可见焦点、`prefers-reduced-motion`、对比度 | 不宣称完整 WCAG 认证 |

## 2. 参考的业界实现

- **Foxglove Studio**：面板优先布局、连接状态、命令面板/快捷键、回放时间轴。
- **RViz**：固定视角/面板可停靠、状态栏、话题可视化分层。
- **Webots**：运行/暂停/单步/实时因子、场景树与 3D 同屏。
- **GitHub Primer**：空状态、加载态、错误态三件套；按钮层级（primary/default/danger）。
- **WCAG 2.2 SC 2.5.8**：目标尺寸最小 24×24；本项目主要按钮 ≥34–44px。
- **Nielsen 10 条启发式**：系统状态可见、用户控制与自由、错误预防、识别优于回忆。
- **three.js 文档**：`SRGBColorSpace`、ACES tone mapping、DPR 上限 2、OrbitControls 阻尼。

## 3. 仿真工作台（`software/modkit/simui.html`）

### 信息架构

```
顶栏：品牌 / DIGITAL TWIN | 运行状态 · 时钟 | 运行 单步 实时 复位 帮助
断线横幅（仅失败时）
主区：2×2 视图（俯视 / 侧视 / 3D / 相机） + 全宽电压温度曲线 + 6 状态卡
右栏：控制 | 场景 | 诊断 三个标签页（粘性，限高内滚动）
底栏：连接状态 / 后端 / 快捷键提示
```

- **三标签页**：控制、场景、诊断互斥，`aria-selected` + 方向键；选择写入 `localStorage` 与 URL hash。
- **面板聚焦**：每个视图右上角 `⤢`，或 `F` 聚焦当前悬停面板；`Esc` 退出。
- **运行状态机**：`已暂停 / 运行中 / 回放中 / 回放暂停 / 回放完成` 五态，图标、文案、颜色一致。
- **控制合并**：滑杆 45ms 合并请求，避免拖动时打满 HTTP；12s 超时、错误 toast + 日志。
- **故障预设**：标称 / 打滑 / 低电量三键，一次写入 7 个故障参数，滑杆同步。
- **曲线**：双 Y 轴（电压 9–13V、温度 20–80℃）、10.8V 阈值虚线、面积渐变、末值点、最近采样计数。
- **场景**：选场景 → 运行 → PASS/FAIL 卡（帧数/耗时/摘要）→ 回放/单步/导出 JSON/复制分享链接。
- **编辑器**：`<dialog>` 内编辑 JSON，实时校验行号；格式化、Ctrl/⌘+Enter 运行、另存为；未保存关闭拦截。
- **帮助**：`?` 打开原生 dialog，列出全部快捷键。
- **移动端**（≤760px）：视图四选一（俯视/侧视/3D/相机），曲线与状态卡保留，右栏移到主区下方。

### 视觉

- 深色分层：`#0b1119` 底、`#111822` 卡、`#1b2735` 线；强调色 `#4c9fe8`；状态绿/黄/红。
- 字体：界面用系统无衬线，数字统一 `ui-monospace` + `tabular-nums`，避免跳动。
- 目标：顶栏按钮 36–38px，标签 38px，预设 34px；全部有 `:focus-visible` 环。
- `prefers-reduced-motion` 下关闭过渡/动画。

## 4. 在线查看器（`web/index.html` + `viewer.js`）

### 结构

```
顶栏：品牌 | 文档/GitHub/发布 | 3D 状态 | 帮助
左：3D 舞台（标题/说明/参数 chips、视角切换、HUD、提示条、急停）
右：模型探索 | 真机调试 两个标签页
底栏：状态 / 数据来源 / "仿真≠实物" / 文档
```

- **模型探索**：四个带单位与量程提示的滑杆；播放/复位 + 阶段 + 进度条；快捷键卡。
- **真机调试**：安全提示、连接/断开、扭矩/下发/跟随/记录、演示数据、反馈表、日志清空。
- **安全确认**：首次扭矩或下发前弹出 `<dialog>`，必须勾选"手臂垫空/急停可用/ID 已核对"；确认后本会话不再重复。
- **连接状态**：`未连接 → 已连接 1Mbps`；断开释放 reader/writer/port；急停按钮仅连接后显示。
- **降级**：WebGL 创建失败显示说明层，参数与串口逻辑仍尽量可用；vendor 缺失给出明确提示。
- **快捷键**：`Space` 播放/暂停、`R` 复位、`1–4` 视角、`?` 帮助。
- **移动端**：舞台 54vh，说明收起，参数与真机面板下移；无横向滚动。

### 视觉

- 浅色纸感：`#f4f7fb` 背景、白色卡、`#dbe4ef` 线、`#1d5f96` 强调；3D 地面与页面同色系。
- 舞台圆角 22px、轻阴影；标题用 `clamp()`，窄屏降级。
- 3D 色彩管理：`SRGBColorSpace` + ACES；DPR 上限 2；OrbitControls 阻尼。
- 按钮至少 38px，视角按钮 32/34px；可见焦点；状态用 `aria-live`。

## 6. 已知边界

- 没有前端构建链：工作台仍是单文件 HTML，查看器仍是原生 JS；换取"复制即用"，不引入打包器。
- Web Serial 只在 Chrome/Edge + https/localhost 可用；Safari/Firefox 会明确提示。
- 真机安全确认是软件层防呆，不能替代硬件急停、限流与机械限位。
- 3D 模型是尺寸驱动的简化件，不是 CAD 逐面渲染；用于姿态/空间关系，不用于干涉检查。
- 触控目标按 ≥34px 设计，未逐项达到 44px；后续可按 WCAG 2.5.5 再抬一档。
