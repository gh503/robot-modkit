# 74 · 实体盒网格碰撞与关节静+动力矩

> 状态：**v1.22.0 已实现**。入口：`assemble validate` / Studio 校验页。

## 74.1 从 AABB 到三角面

v1.21 之前碰撞只有世界 AABB：

- 两个旋转 45° 的长条，AABB 可能大面积重叠，但实际并不相交；
- 也可能 AABB 重叠很小，却有尖角互穿。

v1.22 保留 AABB 做**粗筛**，对每对非相邻、AABB 重叠 >1mm 的组件：

1. 用 `bbox` 的 8 个角、12 个三角面构造**实体盒网格**；
2. 对两两三角面做边-三角相交（双向 6 条边）；
3. 额外检查“一个盒子的 8 个角全在另一个盒子里”（完全包含）。

命中时记 `collision.mesh`；同时保留 `collision.aabb`，旧报告/测试仍能按原代码过滤。
`strict` 下 `collision.mesh` 升级为 error。

### 字段

```json
{
  "collision_stats": {"aabb_pairs": 2, "mesh_tests": 2, "mesh_hits": 1},
  "collision_mesh": [{"a": "m1", "b": "p2", "volume_mm3": 1234.5}]
}
```

`aabb_pairs` 是粗筛命中数，`mesh_tests` 是实际三角面测试数，`mesh_hits` 是真实相交数。

### 它不是 CAD 网格

组件库只有 `bbox`，没有 STEP/B-Rep 三角剖分。所以这是**盒网格**，
对“L 形/带孔/薄壁”仍然保守；不能替代 CAD 实体干涉。
它的价值是排除旋转盒的假阳性，并给出比 AABB 更可信的相交判断。

## 74.2 关节静+动力矩

旧版只算重力，而且力臂用当前姿态的 **XY 水平距离**；m1 默认竖直臂
会得到 0 N·m，看起来“永远安全”。v1.22 改成：

```text
力臂 = |COM_下游 - 关节中心|          （3D 距离，等价于手臂转到水平）
重力扭矩 = m × 9.81 × 力臂
动态扭矩 = m × max_accel × 力臂
合计     = 重力 + 动态
比例     = 合计 / 额定扭矩
```

- 下游质量包含工具端载荷 `payload_g`（在工具 tip 处）。
- `max_accel_m_s2` 来自装配文件，默认 0.5；网页显示该值。
- `>1.0` 记 `joint.overload`（error）；`>0.5` 记 `joint.margin`（warn）。
- 仍**不是**完整动力学：不含角加速度、转动惯量、摩擦、冲击、舵机堵转曲线。

### 字段

```json
{
  "instance": "yaw", "name": "yaw", "servo_id": 1,
  "mass_g": 675.8, "arm_mm": 188.5,
  "gravity_nm": 1.25, "dynamic_nm": 0.06, "accel_m_s2": 0.5,
  "load_nm": 1.31, "rated_nm": 2.94, "ratio": 0.45,
  "margin_nm": 1.63, "ok": true
}
```

m1：yaw 0.45×、shoulder 0.34×、elbow 0.11×；都在 50% 以下。

## 74.3 UI / CLI

- Studio 校验页新增“关节力矩（静+动）”表：下游 g、力臂 mm、重力、动态、合计、
  额定、比例；>50% 黄、>100% 红。
- `assemble validate` 人类可读输出增加一行最大力矩与碰撞统计。
- `assemble plan` 的 `assembly.md` 增加力矩表（重力/动态/合计/额定/比例）。
- `--json` 输出 `joint_loads`、`collision_mesh`、`collision_stats`。

## 74.4 测试

- Python 单元：两个盒子相交/分离/包含/旋转；m1 力矩分项相加、比例、servo id。
- 合成装配：AABB 重叠的 m1/p1 结构，同时出现 `collision.aabb` 与 `collision.mesh`。
- 浏览器“网格碰撞/关节力矩”组：`meshHit` 三例、m1 三个关节、力矩表 3 行。
- 总计 **288 项** pytest；`make web-smoke` **12 组**。

## 74.5 边界

- 盒网格，不是 STEP 实体；薄壁/孔/倒角仍可能误判。
- 静+动载是**最坏姿态上界**，不是轨迹仿真；实际峰值取决于控制曲线。
- 额定扭矩来自组件库，不是实测堵转曲线；温度/电压降额未计。
- 物理闸门仍 **0/5**；没有实物碰撞/力矩标定。
