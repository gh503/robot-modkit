## 按类型（Diátaxis 四象限）

混着写是新手迷路的主因，所以每篇只归一类：

| 类型 | 回答什么问题 | 文档 |
|---|---|---|
| **教程**（Tutorial） | "带我走一遍，能成" | [07 小白手册](07-小白操作手册.md) |
| **操作**（How-to） | "我要做 X，怎么做" | [05 装配](05-装配手册.md)、[06 调试](06-调试与测试.md)、[09 故障排查](09-故障排查.md)、[12 仿真](12-仿真与可视化.md)、[15 生产链路](15-生产链路总览.md) |
| **参考**（Reference） | "这个参数/寄存器/零件是什么" | [02 接口规范](02-接口规范.md)、[04 BOM](04-BOM.md)、[11 零件清单](11-零件清单.md) |
| **解释**（Explanation） | "为什么这么设计" | [00 计划](00-项目计划.md)、[01 系统设计](01-系统设计.md)、[03 配电](03-配电与线束.md)、[08 学习路径](08-学习路径与参考.md)、[10 决策记录](10-决策记录.md)、[13 业界实践](13-业界实践对照.md)、[16 可制造性](16-可制造性报告.md)、[17 成本](17-成本模型.md) |

## 编号只是历史顺序

`00` 到 `13` 是按写作时间排的，不代表阅读顺序。找不到东西时看这张表，别从头翻。

## 还有两处非文档入口

- **代码**：`cad/`（图纸）、`firmware/`（固件）、`software/`（上位机）、`sim/`（仿真）、`web/`（查看器）
- **发布**：[Releases](https://github.com/gh503/robot-modkit/releases) 有打包好的 STEP/STL/图片
