# 53 · 相机畸变与手眼标定

> 固定俯视 + 完美针孔是"实验室假设"。真机上镜头有畸变，相机装歪了、标定板没摆准，
> 检测中心会系统偏几毫米到几十毫米。这篇加两个误差源，并给一条标定路径。

## 1. 畸变模型

Brown–Conrady（只取前两项径向 + 切向）：

```
r² = x² + y²
radial = 1 + k1·r² + k2·r⁴
xd = x·radial + 2·p1·x·y + p2·(r² + 2x²)
yd = y·radial + p1·(r² + 2y²) + 2·p2·x·y
u = cx + fx·xd,  v = cy + fy·yd
```

反投影用不动点迭代 12 次，往返误差 <1e-6mm（测试覆盖 k1=±0.15/0.25）。

**重要**：有畸变时像素→桌面不再严格仿射。抓取改用 `Camera.unproject()`；
`table_calib()` 只在视野中心做局部仿射拟合（<8mm），给旧接口/四点标定用。

```bash
modkit camsim --out dist.png --cube 200,0,40 --detect --k1 0.25 --k2 -0.08
```

## 2. 手眼标定

平面相似变换（标定板 → 臂基座）：

```
p_base = s·R(θ)·p_meas + t
```

`calib.HandEye.fit()` 用 Umeyama 2D 从 ≥3 组对应点最小二乘求解；
`inverse()` 生成"真实→测量"的误差，用来注入未标定状态。

场景键：

```json
{"cmd":"mission", ..., "handeye":[45,-20,2.5], "calibrate":true}
```

- `handeye`: 真实标定残差 `[dx mm, dy mm, dyaw°]`；
- 不加 `calibrate`：按误差偏着抓 → 偏移 > `grasp_tol`（默认 15mm）判"抓空"；
- 加 `calibrate`：用 5 点标定板拟合，残差 0.00mm，正常抓。

## 3. 场景

| 场景 | 说明 | 结果 |
|---|---|---|
| `mission_distortion` | k1=0.25/k2=-0.08，反投影抓取 | 7.8s 通过 |
| `mission_handeye_calibrated` | 45mm/2.5° 误差 + 标定 | 7.8s 通过，误差 0.0mm |
| `handeye_offset` | 同样误差但不标定 | 抓空，期望失败 |

## 4. 真机标定流程

1. 打一张 5 点标定板（中心 + 四角，间距 80mm），平放桌面；
2. 机器人依次把末端对准 5 点，记录**基座坐标**；
3. 相机拍板，检测 5 点像素；
4. `HandEye.fit(pixels_mm, base_mm)`（真机需先把像素经内参/畸变转成平面 mm）；
5. 把 `dx/dy/dyaw/scale` 写进配置，重跑 5 点，残差应 <2mm；
6. 每换相机/支架/碰撞后重标。

## 5. 边界

- 畸变只到 k1/k2/p1/p2，没有高阶/鱼眼/rolling shutter；
- 标定是平面相似变换，不含深度/倾斜（相机光轴仍垂直桌面）；
- 标定板点由仿真真值生成，真机要处理检测误差/离群点（RANSAC 未做）；
- 没有自动内参标定（fx/fy/cx/cy 仍给定）。
