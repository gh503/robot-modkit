# 38 · 导航基础（M2 第一步）

> 里程计标定（[29](29-里程计标定.md)）解决"我走了多远"；这一篇解决"我怎么走到那个点"。
> 先做**纯控制器 + 理想单轮车**：没有硬件也能把边界跑完，真机只差一层轮速下发。

## 1. 控制器

`software/modkit/nav.py`，输入当前位姿 `(x, y, θ)` 和目标位姿，输出 `(v, ω)`：

1. 位置误差 <8mm 且朝向误差 <3° → 停；
2. 位置到了但朝向不对 → 原地转；
3. 朝向差 >50° → 原地转（避免画大弧）；
4. 否则边走边修：`v = v_max · min(1, dist/120) · cos(方位误差)`，`ω = k·方位误差`。

默认：`v_max=150mm/s`、`ω_max=90°/s`、`k_rot=2.5`、`k_lat=2.0`。

## 2. 仿真结果

```bash
modkit nav --path square --size 300
```

| 段 | 目标 (mm,°) | 用时 | 终点误差 | 朝向误差 |
|---|---|---:|---:|---:|
| 1 | (300, 0, 0) | 3.1s | 7.9mm | 0.0° |
| 2 | (300, 300, 90) | 4.6s | 8.0mm | 2.9° |
| 3 | (0, 300, 180) | 4.6s | 7.7mm | 2.9° |
| 4 | (0, 0, 270) | 4.6s | 7.6mm | 2.9° |

方形闭环回到起点 **7.6mm** 内，总耗时约 17s。判据：每段 ≤12mm / ≤5°，否则命令退出码 1。

直线单点：

```bash
modkit nav --path line --size 500
```

## 3. 闭环：走完整协议栈

`--closed-loop` 不再用理想模型，而是：

```
控制器 → Robot.drive_speed() → 0x2E 速度寄存器（带方向位）
       ← Robot.update_odom() ← 0x38 位置计数（4096 一圈）
```

`SimLink(wheels=True)` 在内存里积分差速底盘，所以这条链路和真机走的是同一套协议。

```bash
modkit --sim nav --closed-loop --path square --size 300
```

| 段 | 目标 | 用时 | 误差 |
|---|---|---:|---:|
| 1 | (300, 0, 0) | 3.0s | 7.7mm / 0.0° |
| 2 | (300, 300, 90) | 4.4s | 7.6mm / 2.9° |
| 3 | (0, 300, 180) | 4.4s | 7.7mm / 2.9° |
| 4 | (0, 0, 270) | 4.4s | 7.7mm / 2.9° |

闭环方形 **7.7mm / 2.9°**，16.2s。轮速测试：`modkit --sim drive --v 100 --w 0 --seconds 1`
（1 秒走 99.8mm，速度寄存器 1 LSB = 1°/s 的仿真占位）。

**两个坑**（已处理）：

1. 位置计数过零：`tick_delta()` 按 4096 取最短路径；但单次读数不能跨半圈（约 102mm），
   所以闭环必须 ≥20Hz 读里程计。`navigate()` 默认 50Hz。
2. `speed_unit` 只是占位：真机 1 LSB 对应多少 °/s 必须按 [06](06-调试与测试.md) G7 实测；
   左右轮方向也要按接线确认。

## 4. 真机怎么接

控制器输出的是 `v`（mm/s）、`ω`（°/s），换算成左右轮线速度：

```python
from modkit import kinematics as kin, nav
left, right = kin.wheel_speeds(v, w, kin.DriveGeometry())
```

再写进舵机速度寄存器（`0x2E`，最高位方向），代码在 `Robot.drive_speed()`；
`modkit --sim drive --v 100 --w 0` 可单独试轮子。

真机顺序：先 `0x21=1` 切恒速模式 → 标定 `speed_unit` 和左右方向 → 再跑 `nav --closed-loop`。
目前真机闭环被 CLI 主动拦住，避免没标定就上车。

## 5. 现在没做的

- 没有定位：位姿来自里程计，走久会漂（需要视觉/二维码/激光）；
- 没有避障、没有速度平滑（加速度突变会让轮子打滑）；
- 没有打滑检测；
- 理想模型里 `v` 立即生效，真机有加减速和死区。
