# 81 · 流体材料与工程计算

> 状态：**v1.32.0 已实现**。目标：给机器人/世界仿真一套**可解释、可调整、可复现**的
> 流体物性层和工程公式；不是 CFD，不替代水池试验。
> 物理闸门仍 **0/5**。

## 81.1 它解决什么问题

泳池清洗、管道检查、灌溉、冷却液泄漏、食品/涂料处理，机器人面对的第一组约束不是
“用哪个舵机”，而是：

- 水有多重、阻力多大、泵要多大、管径够不够；
- 液体是牛顿流体还是 Bingham/屈服应力流体；
- 温度/盐度变了，密度和粘度怎么变；
- 同样的方案，在淡水、海水、冷却液里差多少。

`modkit.fluid` 用统一 schema 描述这些，并给出**手算可复核**的公式。它不求解完整
Navier–Stokes；复杂流场用 `world` 的降阶模型或外部 CFD。

## 81.2 一条命令看材料

```bash
cd software
../.venv/bin/python -m modkit.cli fluid list
../.venv/bin/python -m modkit.cli fluid show water
../.venv/bin/python -m modkit.cli fluid show seawater --temp 4 --salinity 35
../.venv/bin/python -m modkit.cli fluid compare water hydraulic_oil
```

`show` 会打印密度、动力/运动粘度、表面张力、屈服应力、体积模量、pH、颜色/透明度、
导热/比热/热膨胀等；`--json` 给程序读。

## 81.4 支持哪些属性

| 字段 | 单位 | 必填 | 说明 |
|---|---|---|---|
| `key` | — | ✅ | 唯一标识；场景引用它 |
| `name` / `name_en` | — | ✅ | 显示名 |
| `category` | — | ✅ | water/oil/gas/solution/food/slurry/foam |
| `density` | kg/m³ | ✅ | 20°C 密度 |
| `viscosity` | Pa·s | ✅ | 动力粘度；非牛顿用零剪切近似 |
| `surface_tension` | N/m | — | 默认 0；Weber/毛细长度用 |
| `yield_stress` | Pa | — | >0 即 Bingham；管道压降给警告 |
| `bulk_modulus` | Pa | — | 压缩性；气体默认为 101325 |
| `vapor_pressure` | Pa | — | 空化/汽蚀判断的输入，当前不自动算 |
| `ph` | — | — | 水质/材料兼容性元数据 |
| `temperature_c` | °C | — | 参考温度，默认 20 |
| `color` / `opacity` | hex / 0..1 | — | 查看器/报告显示 |
| `thermal_conductivity` | W/mK | — | 换热方案 |
| `specific_heat` | J/kgK | — | 热惯性 |
| `thermal_expansion` | 1/K | — | 液体密度温度修正 |
| `viscosity_b_k` | K | — | Andrade 粘度-温度曲线参数 |

派生量：`kinematic_viscosity = viscosity / density`、`is_gas`、`is_bingham`。

## 81.5 怎么添加流体

### 方式 A：命令行校验并导出注册表

```bash
cat > /tmp/my-fluid.json <<'JSON'
{
  "key": "pool_brine",
  "name": "泳池盐水",
  "name_en": "Pool brine",
  "category": "water",
  "density": 1035,
  "viscosity": 0.0012,
  "surface_tension": 0.071,
  "ph": 7.4,
  "color": "#2f7f9f",
  "opacity": 0.6,
  "notes": "泳池加盐方案，仅方案比较"
}
JSON
../.venv/bin/python -m modkit.cli fluid add --file /tmp/my-fluid.json
```

`fluid add` 只校验并加载到当前进程；加 `--out custom-fluids.json` 会把**合并后的注册表**
导出。`--force` 才允许覆盖同名 key。

### 方式 B：直接放进世界 JSON（推荐）

```json
{
  "custom_fluids": [
    {"key":"pool_brine","name":"泳池盐水","name_en":"Pool brine","category":"water",
     "density":1035,"viscosity":0.0012,"surface_tension":0.071}
  ],
  "fluids": [
    {"id":"water","type":"pool","fluid":"pool_brine","position":[0,0,0.1],
     "size":[8,4,1.5],"level":0.8}
  ]
}
```

`world validate` / `world run` 会先把 `custom_fluids` 注册进材料库，场景就能引用。
同名会覆盖内置值——这是有意的，便于做敏感性分析；但报告会保留 `source`。

### 方式 C：Python

```python
from modkit import fluid as fl
f = fl.get("water").with_properties(density=1035, viscosity=0.0012)
fl.register(f, replace_existing=True)
```

## 81.6 怎么调整

| 想调 | 命令/字段 | 影响 |
|---|---|---|
| 温度 | `fluid show water --temp 40`；场景 `temperature_c` | 粘度按 Andrade 近似下降；液体密度按热膨胀微降 |
| 盐度 | `--salinity 35`；场景 `salinity_ppt` | 仅 water 类；密度 +0.8 kg/m³ per ppt，粘度略升 |
| 密度/粘度 | 自定义 JSON | 阻力、Re、压降、泵功率 |
| 表面张力 | 自定义 `surface_tension` | Weber/毛细长度；浅水求解不用 |
| 屈服应力 | `yield_stress > 0` | 标记 Bingham；管道压降给“需流变仪/管试”警告 |
| 液位 | 场景 `level` 0..1 | 体积、静压、水箱排空 |
| 流量 | 场景 `flow_m3_s` | 管道压降、泵功率、射流力 |
| 颜色/透明度 | `color`/`opacity` | 仅查看器/报告，不影响物理 |

温度/盐度是**近似模型**；真实项目要用流变仪/密度计在目标温度下测。

## 81.7 工程公式与命令

```bash
# 管道：流量 1 L/s，内径 20mm，长 5m
../.venv/bin/python -m modkit.cli fluid pipe --fluid water \
  --flow 0.001 --diameter 0.02 --length 5

# 水箱：1m²、1m 高、出口 10cm²、无补液
../.venv/bin/python -m modkit.cli fluid tank --fluid water \
  --area 1 --height 1 --outlet 0.01 --seconds 5

# 阻力 / 终端速度
../.venv/bin/python -m modkit.cli fluid drag --fluid water --velocity 0.5 --area 0.1
../.venv/bin/python -m modkit.cli fluid terminal --fluid water --diameter 0.001 --particle-density 2500
```

实现：

- 雷诺数 `Re = ρ v L / μ`；层流 `f=64/Re`，湍流用 Haaland 近似；
- 管道 `Δp = f (L/D) ρv²/2 + K ρv²/2`；
- 泵轴功率 `P = ρ g Q H / η`；
- 薄壁孔口 `Q = Cd A √(2gh)`，排空 `t = A_t/(Cd A_o) √(2h/g)`；
- 阻力 `F = ½ ρ Cd A v²`；浮力 `F = ρ V g`；
- 球形颗粒终端速度迭代 Re 修正；
- Manning 明渠 `Q = (1/n) A R^(2/3) √S`。

## 81.8 边界（必须读）

- 不是 CFD：不解析自由表面破碎、气泡、多相、湍流谱、水锤；
- 非牛顿只做 **Bingham 标记 + 等效粘度压降**，不给完整流变曲线；
- 温度/盐度是工程近似，不是热力学状态方程；
- 管道是稳态，不含瞬态/空化/磨损；
- 所有数值用于**方案比较和实验设计**，不用于安全认证或性能保证；
- 物理闸门仍 **0/5**。
