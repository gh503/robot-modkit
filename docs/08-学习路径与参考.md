# 08 · 学习路径与参考

> 只列**你真会用到**的知识，每条都配一个 30 分钟能做完的练习。
> 链接均于 2026-10-24 核验可访问。书籍给的是"读到哪一章"，不是"读完"。

## 0. 学习顺序（别跳）

```
电子基础 → 总线与协议 → 参数化 CAD → 运动学 → 控制 → 视觉 → 导航 → 系统集成
   (1周)      (1周)        (2周)      (2周)    (2周)   (3周)   (3周)    持续
```

跳过的代价：直接学视觉的人，80% 的时间会浪费在"为什么抓偏了"——其实是标定或运动学错了。

---

## 1. 电子基础（1 周）

**要学到什么程度**：能看懂"为什么必须共地"、"为什么加 1000µF"、"为什么 MOS 管要加栅极电阻"。

| 知识点 | 为什么本项目需要 |
|---|---|
| 欧姆定律、分压、功率 | 算线径压降（[03-配电](03-配电与线束.md) §2） |
| 去耦电容、电源纹波 | 舵机换向尖峰会让主控复位 |
| 上拉/下拉、开漏、三态 | 半双工总线的 DIR 控制 |
| 肖特基二极管、自恢复保险丝 | 防反接、过流保护 |

**参考**
- Ben Eater《Building an 8-bit breadboard computer》系列视频 —— 讲清"电信号怎么变成逻辑"：https://eater.net/8bit
- Arduino 官方 Serial 参考（读懂 `Serial.write/flush/available` 的差别）：https://www.arduino.cc/reference/en/language/functions/communication/serial/
- 书：《Practical Electronics for Inventors》第 1–3 章（元件与基础电路）

**练习**：用万用表量你的 12V 适配器空载/带载电压；串一个 1Ω 电阻量舵机堵转电流，和规格书 2.7A 对比。**误差 > 20% 就说明你的测量方法有问题**（比如表笔电阻）。

## 2. 总线与协议（1 周）

**要学到什么程度**：能自己手写一帧、能手算校验和、能用示波器/逻辑分析仪看出"丢了一个字节"。

| 知识点 | 对应实现 |
|---|---|
| UART 帧：起始位/数据位/停止位 | 8N1，1Mbps |
| 半双工与方向切换 | `IHalfDuplexBus::setDirectionTx` |
| 校验和（取反求和） | `checksum()` |
| 主从问答、广播、同步写 | `PING` / `0xFE` / `0x83` |
| 字节序 | STS 是小端 |

**参考**
- 飞特官方协议（帧格式、指令表、示例）：https://ftservo.github.io/ftservo-wiki/reference/protocol/ft-scs/
- STS 内存表（每个寄存器的地址/位域）：https://ftservo.github.io/ftservo-wiki/reference/parameter/memory-sts/
- Robotis Dynamixel 协议 2.0 —— 另一套成熟的总线舵机协议，对照着看能理解"为什么这样设计"：https://emanual.robotis.com/docs/en/dxl/protocol2/

**练习**：不看代码，手写 `PING` 给 ID=3 的舵机（答案：`FF FF 03 02 01 F9`），然后用 `modkit.protocol.encode` 验证。
再手算一次校验和：`~(0x03+0x02+0x01) & 0xFF`。

## 3. 参数化 CAD（2 周）

**要学到什么程度**：能改一个变量让 5 个零件自动更新；能判断"这个孔打 3.4 还是 3.2"。

| 知识点 | 对应实现 |
|---|---|
| 草图/拉伸/布尔 | `parts.py` 里每个零件就是一个布尔表达式 |
| 参数化与单一数据源 | `params.py` |
| 公差与配合 | `M3_CLR=3.4`、`FIT_CLR=0.4` |
| FDM 收缩、悬空角、壁厚 | 打印参数表（[05-装配](05-装配手册.md)） |
| 干涉检查 | `build.py` 的 `a & b` 体积断言 |

**参考**
- build123d 文档（本项目用的库，Python 代码建模）：https://build123d.readthedocs.io/
- FreeCAD 官方文档（想用图形界面时）：https://wiki.freecad.org/
- 同款舵机的开源机械臂（看别人怎么设计舵机支架）：https://github.com/TheRobotStudio/SO-ARM100

**练习**：把 `LINK_L` 从 100 改成 140，跑 `build.py`，观察打印件尺寸与紧固件清单是否同步变化；再把 `M3_CLR` 改成 3.0，解释为什么自检不报错但实际装不上（提示：自检只查几何，不查工艺）。

## 4. 运动学（2 周）

**要学到什么程度**：能手推 2 连杆逆解；能解释"为什么同一个点有两组解"；知道奇异点在哪。

| 知识点 | 对应实现 |
|---|---|
| 正运动学（DH / 几何法） | `forward()` |
| 2 连杆逆解、余弦定理 | `inverse()` |
| 多解与肘上/肘下 | `elbow_up` 参数 |
| 工作空间 | `reach_min/max` |
| 差速里程计 | `update_odom()` |
| 坐标系变换 | 相机→base_link（M3） |

**参考**
- 书：《Modern Robotics: Mechanics, Planning, and Control》(Lynch & Park) 第 4–6 章（正逆运动学），作者官网提供免费预印本与课程视频
- 书：《Robotics: Modelling, Planning and Control》(Siciliano) 第 2–3 章
- ROS REP-103（坐标轴约定，务必看）：https://www.ros.org/reps/rep-0103.html

**练习**：在纸上推一遍 `inverse()` 的肩角公式，然后故意把 `+` 改成 `−`，跑 `pytest`，看是哪条测试抓住你（这条测试就是为这个 bug 存在的）。

---

## 5. 控制（2 周）

**要学到什么程度**：能调一个 PI 速度环；知道为什么"积分项会让机械臂冲过头"。

| 知识点 | 用在哪 |
|---|---|
| 开环 vs 闭环 | 轮子先开环跑 2m 量偏差 |
| PID 三项的物理意义 | 速度环、位置环 |
| 采样周期与延迟 | 控制周期 20–50ms |
| 前馈与轨迹规划 | 点到点运动太"生硬"时 |

**参考**
- 书：《Feedback Control of Dynamic Systems》(Franklin) 第 4–6 章，或任何 PID 入门
- ROS 2 control 框架（看工业界怎么组织控制器）：https://github.com/ros-controls/ros2_control

**练习**：给 `wheel_speeds()` 写一个 PI 控制器（先只在你自己的脚本里），目标是让轮子达到指定 mm/s。
用 `SimLink` 模拟"实际速度比指令慢 20%"，看积分项多久能把误差消掉。

---

## 6. 视觉（3 周）

**要学到什么程度**：能完成一次相机内参标定；能解释"像素坐标为什么不能直接当米用"。

| 知识点 | 用在哪 |
|---|---|
| 针孔模型、内参/畸变 | 相机标定 |
| 颜色空间 HSV | 方块检测（比 RGB 稳） |
| 轮廓、面积、中心 | 目标定位 |
| 单应/平面假设 | 桌面抓取 |
| 手眼标定 | 相机→base_link |

**参考**
- OpenCV 官方文档（相机标定与 3D 重建章节）：https://docs.opencv.org/4.x/
- ROS 2 URDF 教程（描述机器人几何，做 TF 用）：https://docs.ros.org/en/humble/Tutorials/Intermediate/URDF/URDF-Main.html
- Hugging Face LeRobot（看别人怎么把视觉+机械臂+数据串起来）：https://github.com/huggingface/lerobot

**练习**：用手机拍一张方格纸，用 OpenCV 找出角点并画出来（`findChessboardCorners`）。
再故意把纸倾斜 30°，观察角点顺序是否仍然正确 —— 这是标定失败最常见的原因。

---

## 7. 导航（3 周，M4 阶段）

**要学到什么程度**：能让机器人在 3×3m 房间里从 A 走到 B，不撞椅子。

| 知识点 | 用在哪 |
|---|---|
| 占据栅格地图 | 建图 |
| A*/Dijkstra | 全局路径 |
| DWA/TEB | 局部避障 |
| AMCL / 粒子滤波 | 定位 |
| 代价地图 | 膨胀障碍物 |

**参考**
- nav2 官方文档（ROS 2 的导航栈，教程完整）：https://docs.nav2.org/
- ROS 2 Humble 官方教程：https://docs.ros.org/en/humble/
- 书：《Probabilistic Robotics》(Thrun) 第 6–8 章（定位与建图）

**练习**：先用"贴纸地标 + 里程计"做最简单的点到点导航（不开 ROS），跑通再换 nav2。
你会更理解 nav2 每个模块在解决什么问题。

## 8. 系统集成（持续）

**要学到什么程度**：任何一个新功能，都能回答"它的失败模式是什么、我怎么测出来"。

| 能力 | 判断标准 |
|---|---|
| 分层设计 | 换主控不改业务代码 |
| 可测试性 | 没硬件也能跑 80% 的逻辑 |
| 日志与回放 | 失败能复现 |
| 版本管理 | 每次改动可回退 |
| 文档 | 三个月后的自己能接上 |

---

## 9. 一份"不要读"的清单

- ❌ 一上来读 SLAM 论文（先让轮子走直线）
- ❌ 一上来学强化学习（先有稳定的底层）
- ❌ 一上来买 Jetson（先让 200 行 Python 跑通）
- ❌ 一上来做自重构、双足（先把 4 自由度臂抓稳）

**这些不是没用，是时机不对。** 每一样都会在你把地基打好之后变得容易十倍。
