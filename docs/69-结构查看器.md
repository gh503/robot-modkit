# 69 · 结构查看器（自由设计 3D）

> 状态：**v1.18.0 已实现**。入口：
> <https://gh503.github.io/robot-modkit/view.html>

## 69.1 解决什么

`design.html` 是**设计器**：能加/换/删件、改参数、拖关节、做预算和导出，但界面重。
`index.html` 是 **M1 实时查看器**：只渲染写死的 M1（`scene.js`），不读取自由设计。

`view.html` 是两者之间的只读 **结构查看器**：给一份装配 JSON，按组件元数据建 3D，
只做“看结构、点选、读校验摘要”，避免为了看一眼设计而打开整个编辑器。

## 69.2 输入

| 入口 | 行为 |
|---|---|
| `view.html#d=<base64url JSON>` | 解码 → `A.check()` → `A.validate()` → 建网格 |
| Studio 顶部 **3D 查看** | 用当前 `state.assembly` 生成 `view.html#d=...`，新标签页打开 |
| `view.html?preset=m1` | 看某个预设（方便对比） |
| `view.html`（无参数） | 回退到 M1 演示，并标注“未提供设计” |
| `index.html#d=...` | 自动 `location.replace` 到 `view.html#d=...`，旧链接也能用 |

分享链接过大（>60000 字符）时，Studio 会拒绝并提示导出 JSON。

## 69.3 渲染与交互

- 复用 `assembly-core.js` 的树/端口求解：每个组件有世界矩阵，offboard 电源不建几何。
- 组件网格按 `MODKIT_COMPONENTS` 的 `bbox/dims/category/cad/tool` 生成，
  与设计器同一套几何；关节按 `joint.center` 建 pivot。
- **关节运动**：位置关节有滑杆（度/比例），播放按正弦扫过 min→max；
  夹爪按 ratio 开合，驱动轮在播放时旋转；复位清零。
- **爆炸视图**：每个非根件沿“装配中心 → 自身”方向偏移 20mm，再适配视角；再点收起。
- 运动是**运动学示意**，不计算动力学、负载、真实碰撞。
- 左键旋转、右键平移、滚轮缩放、点击选中（蓝色包围盒 + HUD 显示 id/名称）。
- “适配视角”按整体包围盒重新取景；地面/网格跟着最低点走。
- 右侧显示组件数、估算质量、BOM、位置关节、预算差、错误/警告摘要。
- “在 Studio 编辑”把当前装配重新编码成 `design.html#d=...`，进入编辑器。
- “复制链接”复制当前 `view.html#d=...`。

## 69.4 边界

- **只读**：不能在查看器里换件/改参数/拖关节；这些仍回 Studio。
- 几何是**按组件元数据重建的视觉网格**，不是 STEP 实体；碰撞/静载仍是 AABB/保守估算。
- 没有后端；分享数据全在 URL hash，刷新/离线（Service Worker）都不上传。
- 物理闸门仍是 **0/5**：查看器不改变任何实物验证状态。

## 69.5 验证

- 11 个预设都能在 `view.html?preset=...` 打开；`sensor_tower` 的 offboard 电源不建几何但计入 BOM。
- 浏览器实测 m1：18 组件、2590 三角形、60 draw calls；点选 `chassis` 有包围盒和 HUD。
- 4 个关节滑杆、2 个驱动轮、1 个夹爪；播放/爆炸/复位均通过 `make web-smoke`。
- `index.html#d=...` 重定向到 `view.html#d=...`；分享链接 / 无效链接都有明确提示。
- 静态测试覆盖页面 hooks、PWA shell、Studio 按钮；总计 **310 项** pytest。
