# 18 · 质检与验收

> 这份文档的目标：**别人问你"这台合格吗"，你能拿出记录，而不是说"感觉还行"。**
> 分三道关：来料/打印件 → 装配 → 整机功能。每关都有"测什么、怎么测、多少算过"。

## 1. 三道关与门禁

| 关 | 什么时候 | 判据 | 记录 |
|---|---|---|---|
| Q1 零件 | 打印/收货后 | 关键尺寸在公差内、无层裂、螺母能压入 | 每件一行 |
| Q2 装配 | 装完一半/整机 | 关节无卡滞、轮子共面、线序正确、急停有效 | 每台一份 |
| Q3 整机 | 上电后 | 10 次抓放 ≥8 成功、重复精度 <2mm、温升 <55℃ | 每台一份 |

批次规则：**首件全检，之后每 5 台抽 1 台做 Q3**；任一台 Q3 不合格，整批回查。

> 逐件尺寸/克重/关键检查项见 [35-来料检验表](35-来料检验表.md)（自动生成）。

## 2. Q1 · 零件验收

### 2.1 必测尺寸（用 0–150mm 卡尺，精度 0.02）

| 零件 | 测什么 | 标称 | 公差 | 超差后果 |
|---|---|---|---|---|
| 全部 | 板厚 | 4.0 | ±0.2 | 螺母压不齐 / 螺丝不够长 |
| joint_base | 舵机腔宽 | 25.1 | +0.2/−0.1 | 舵机塞不进或晃 |
| joint_base | 角柱孔距（±26） | 52.0 | ±0.2 | 盖板装不上 |
| 全部 | M3 通孔 | Ø3.4 | +0.15/−0.05 | 螺丝拧不进 |
| 全部 | 热熔螺母底孔 | Ø4.2 | ±0.1 | 螺母压裂或打滑 |
| chassis_* | 左右半对接孔距 | 200.0 | ±0.3 | 连接板对不上 |
| drive_bracket | 舵机安装孔距 | 见工程图 | ±0.2 | 舵机装不进 |

> 工程图：[drawings/modkit-m1-drawings.pdf](drawings/modkit-m1-drawings.pdf)（每页有孔表）

### 2.2 外观与工艺

- [ ] 无层间开裂、无翘边（翘曲 >1mm/100mm 判不合格）
- [ ] 圆孔内无支撑残留（有的话用 3mm 钻头手工过一遍）
- [ ] 热熔螺母：压入后与表面齐平 ±0.3，**拉力 ≥50N 不脱出**（手拽 + 弹簧秤）
- [ ] 螺纹孔：M3 螺丝能单手拧到底，不滑牙

### 2.3 首件特别检查

首件必须做 **装配试配**：拿真实舵机塞进 joint_base，手感是"能进、不晃"。
太紧→用砂纸修 0.1mm；太松→贴一层 0.2mm 胶带应急，正式件改参数重打。

## 3. Q2 · 装配验收

### 3.1 机械

- [ ] 每个关节手动转动：全程无卡滞、无异常声响
- [ ] 关节回差：固定底座，末端左右各加 200g，位移 <2mm
- [ ] 四轮共面：平板玻璃上，任一轮离地 <1mm（塞尺）
- [ ] 夹爪闭合：两爪尖间隙 <1mm，且不碰
- [ ] 所有 M3 螺丝：扭矩 0.4N·m（手感"拧紧后再 1/8 圈"），热熔螺母处不要超过 0.3N·m

### 3.2 电气

- [ ] 万用表蜂鸣档：12V 正负极**不短路**
- [ ] 上电前测绝缘：正极对壳体 >1MΩ
- [ ] 舵机 ID 与 `docs/03` §5 一致（`modkit calib --action scan`）
- [ ] 急停按下：舵机 12V 应为 0V；复位后恢复
- [ ] 保险丝规格 5A，座子无松动

## 4. Q3 · 整机功能验收

### 4.1 标定（必须先做）

```bash
modkit calib --port /dev/ttyUSB0 --action scan          # 6 个 ID 都在
modkit calib --action limits --id 1 --lo 0 --hi 180     # 逐个关节测限位
modkit calib --action zero --id 1 --name yaw --deg 90 --save calibration.json
modkit calib --action verify --file calibration.json    # 误差 <2°
```

标定记录 `calibration.json` 随机器存档；换舵机/换关节必须重标并更新版本号。

### 4.2 性能

| 项 | 方法 | 判据 |
|---|---|---|
| 抓放成功率 | 100g 方块，10 次 | ≥8 次 |
| 重复精度 | `modkit bench --action repeat --n 10` + 卡尺/千分表复核 | 离散 <2mm |
| 末端定位 | 3 个已知点，对比指令 | 误差 <2mm |
| 连续运行 | 30 分钟循环抓放（`modkit bench --action burnin --minutes 30`） | 无停机；舵机壳温 <55℃；CSV 留档 |
| 堵转保护 | 手动挡住夹爪 2 秒 | 限流生效，不冒烟、不烧保险 |
| 续航（电池档） | 满电到低压保护 | ≥40 分钟 |

### 4.3 记录表（用 `modkit qc` 生成，不要手抄）

```bash
modkit qc --action new --operator 老王            # 自动取下一个序列号
modkit qc --action validate records/M1-2026-0001.json
modkit qc --action summary records/*.json
```

记录里包含以下字段（JSON）：

```
序列号：M1-2026-____        装配人：______        日期：______
Q1 零件：合格 __ / 不合格 __        备注：____________
Q2 装配：机械 __ / 电气 __          备注：____________
Q3 功能：抓放 __/10   重复精度 __mm  温升 __℃   续航 __min
标定文件：calibration-M1-2026-____.json    sha256：____________
结论：合格 / 返修 / 报废            签字：______
```

## 5. 不合格怎么处理

| 现象 | 先查 | 处理 |
|---|---|---|
| 孔小装不进 | 校准件哪一档合适 | 换档重打；急用可铰刀扩 0.1 |
| 螺母打滑 | 底孔是否超差 | 换大一号螺母（M4）或环氧补 |
| 关节卡滞 | 同轴度/螺丝过长 | 松开重对；螺丝换短一档 |
| 舵机发热 | 是否长期堵转/增益过高 | 降 `kp`、查限位、加散热 |
| 抓不住 | 夹爪间隙/表面摩擦 | 贴 1mm 硅胶垫；查 `JAW_GAP_OPEN` |

**返修后的机器必须重跑 Q3**，并在记录里注明返修项。

## 5.5 台架测试（可自动化）

```bash
# 重复精度：同一点往返 10 次，编码器口径
modkit --port /dev/ttyUSB0 bench --action repeat --n 10 --x 180 --y 0 --z 120

# 烧机：1 分钟快速验证 / 30 分钟正式
modkit --port /dev/ttyUSB0 bench --action burnin --minutes 30 --limit 55 --csv bench-M1-2026-0001.csv
```

- 仿真先跑：`modkit --sim bench --action repeat`
- 烧机 CSV 字段：时间、循环、温度、电压、末端 x/y/z
- 超温/故障会自动卸力并中止；真机必须有人在场

## 6. 和成本/交期的关系

- Q1 全检约 15 分钟/台；Q2 20 分钟；Q3 45 分钟 → 合计约 **1.3 小时/台**（已含在 `hardware/bom.json` 的 labor 里）
- 抽检比例降到 20% 时，单台质检成本约 0.3 小时；但首件必须全检
