# 04 · 装配工艺 v0.1

> 目标：**一把 2.5mm 内六角、5 分钟、徒手拆换一个关节**。
> 装配顺序不能随意调：先装舵机再装输出盘，再压盖板 —— 反了就得拆。

## 0. 打印件到手先做三件事

| 步骤 | 做法 | 通过标准 |
|---|---|---|
| 去毛刺 | 美工刀刮掉第一层裙边残留 | 手摸无刺 |
| 通孔过一遍 | 用 Ø3.4 钻头**手拧**过一遍所有 M3 孔 | 螺钉能自由穿过、不晃 |
| 试拧 | 拿 M3×12 试拧角柱底孔 | 能进 2–3 牙即合格（接下来要熔螺母） |

> 不要用锤子敲钻头，用手拧或小电钻低速。FDM 孔会收缩 0.1–0.2mm，过一遍能省半小时。

## 0 · 先打校准件（15 分钟，别跳过）

在打 12 个零件之前，先打 `cad/out/print_gauge.stl`（一块 100×96×5 的板）：

1. **M3 过孔**：Ø3.2 / 3.4 / 3.6 三个孔，用 M3 螺钉试穿。
   能轻松穿过又不晃 → 选那一档，回头改 `cad/params.py` 里的 `M3_CLEAR`。
2. **舵机宽度槽**：24.7 / 25.1 / 25.5 三条槽，把 ST-3215 塞进去。
   能进、不晃、不刮壳 → 选那一档，改 `SERVO_RECESS` 相关的槽宽。
3. **翘曲**：板放在平玻璃上，四角不能有明显跷动。翘了先调床温/首层，再打整机。

这一步花几克料，能避免"打完全部才发现孔小了"——这是 3D 打印机器人最常见的返工原因。

拼盘直接打现成的：`cad/out/plate_A.stl`（左底盘+支架+相机+关节）、`plate_B.stl`（右底盘+连接板）、
`plate_C.stl`（小件+校准件）。

## 1. 热熔铜螺母（4 颗）

```
温度 240–260℃，压头垂直下压，看到法兰与塑料面齐平即停
冷却 10 秒再松手 —— 热的时候松手螺母会被带出来
```

| 检查项 | 标准 |
|---|---|
| 上表面齐平 | 允许 +0.2 / −0.3mm |
| 拉力 | 手指用力拔不动 |
| 通孔通畅 | 螺钉从底部能顺利旋入 5 圈以上 |

**失败处理**：歪了别硬掰，用烙铁重新加热到 250℃ 拔出，换个位置（打印件里每个角柱只给了一个孔位，所以宁可慢）。

## 2. 舵机入槽

1. 舵机出线朝 **+X 侧缺口**（底板上的 10mm 宽槽），线要能自然伸出不绷紧。
2. 舵机"输出轴朝上"放进浅槽，**不要压**：槽是 2.4mm 深、单边 0.2mm 间隙，应该"落进去"而不是"塞进去"。
3. 轻推四角，确认舵机底面与槽底贴合（歪着装盖板会压不到舵机，看起来装上了其实没限位）。

| 检查项 | 标准 |
|---|---|
| 舵机能落到底 | 无倾斜，手指按压无弹跳 |
| 出线不绷紧 | 线在缺口处有余量，弯折半径 ≥ 5mm |
| 侧向旷量 | 目测 < 0.5mm（0.2 间隙 + 打印误差） |

## 3. 输出盘（受扭矩件，最讲究的一步）

1. 把输出盘**从上方套到花键上**，花键插座 Ø6.1，对齐后轻轻下压；
2. 拧原厂 **M3×6** 螺钉（中心孔），扭矩 **0.35 N·m**（手拧到底再轻压 1/8 圈）；
3. 转动输出盘，应能带动舵机轴空转、无卡滞；**轴向不能有明显窜动**。

| 检查项 | 标准 |
|---|---|
| 花键啮合 | 手转输出盘，舵机轴跟着转，无相对滑动 |
| 轴向窜动 | < 0.3mm |
| 与盖板不碰 | 装上盖板后手转无摩擦声 |

> ⚠️ 这里依赖两个 `[TODO]` 尺寸：花键露出高度、原厂舵盘厚度。如果实物花键比 2.0mm 长，
> 输出盘会顶在花键上而不是坐在舵机壳上，表现为"拧紧后转不动"。**先量再改 `params.py`。**

## 4. 盖板

1. 盖板孔 Ø24.6 对准输出盘法兰，**垂直**放下（斜着进会刮花法兰外圆）；
2. 4× **M3×12** 拧进角柱铜螺母，扭矩 **0.5 N·m**；
3. 对角交叉拧（像拧轮胎螺丝），不要一次拧死一颗。

| 检查项 | 标准 |
|---|---|
| 盖板不压舵机 | 塞 0.3mm 纸片进盖板与舵机之间，能抽动（说明有 0.4mm 间隙） |
| 输出盘自由 | 手转输出盘全程无干涉 |
| 盖板不翘 | 四角贴合，无可见缝隙 |

## 5. 上电与零位标定（不要跳）

```
1. 断电状态下接好 12V、总线、主控
2. 先上 12V，等 2 秒
3. 上主控，跑 scan，确认 4 个 ID 都在
4. 写 0x28 = 0（卸力）
5. 手动把关节摆到机械中位
6. 写 0x28 = 128（当前位置 = 2048）
7. 写 0x28 = 1（出力）
8. 小角度（±5°）试动，确认方向
```

| 检查项 | 标准 |
|---|---|
| 扫描结果 | 4 个 ID 全部应答，无重复 |
| 零位一致性 | 断电重上电后位置读数 = 2048 ± 8 |
| 方向正确 | +角度时朝预期方向转 |

## 6. 装连杆 / 轮毂

- 连杆：4× **M3×10** 穿过连杆进输出盘，扭矩 0.4 N·m；**加平垫**，避免压裂打印件。
- 轮毂：4× M3×10 接输出盘，或 6× M3 接盖板（做被动轮时）。
- 每加一节，都回到 §5 的"小角度试动"再继续 —— **一次只验证一个关节**。

## 7. 拆装演练（验收动作）

用秒表做一次"拆 → 装"：

| 动作 | 目标时间 |
|---|---|
| 拆一个关节（4 螺钉 + 1 中心螺钉） | < 90 秒 |
| 换一只舵机（含重新标定零位） | < 5 分钟 |
| 全模块拆散平铺 | < 10 分钟 |

做不到就回头看：是不是某颗螺钉被别的零件挡住了？——那就是设计问题，改 CAD，不是练手速。

## 8. 螺钉与扭矩速查

| 位置 | 规格 | 扭矩 | 备注 |
|---|---|---|---|
| 盖板→角柱（铜螺母） | M3×12 | 0.5 N·m | 铜螺母可反复 20+ 次 |
| 输出盘→连杆 | M3×10 | 0.4 N·m | 加平垫 |
| 输出盘中心 | M3×6（原厂） | 0.35 N·m | 不要超过 0.5，会压坏舵盘 |
| 底板→结构 | M3×8 + 螺母 | 0.4 N·m | |
| 舵机自带螺钉 | M2.5 自攻 | 0.15 N·m | **本设计不用**（靠浅槽限位） |

## 9. 整机装配（M1）

顺序：**臂 → 底盘 → 合体**。每装一级，单独上电测一次。

### 9.1 臂

1. 底座偏航模块（舵机 1）固定到底盘板上（4× M3×10）
2. 肩关节模块（舵机 2）竖装，立柱 90mm
3. 上臂连杆 120mm → 肘关节模块（舵机 3）
4. 前臂 110mm → 腕 + 夹爪（舵机 4）
5. 每节装完：`home` + 小角度摆动，确认不与上一节干涉

### 9.2 底盘（分三块）

1. 底盘左右两块用 **连接板** 对接：8× M3×10 + 螺母，先别拧死，对完角再紧
2. 驱动支架（drive_bracket）从下方贴住底盘，4× M3×12 穿板固定；左右各一
3. 驱动舵机横躺进支架的托盘里（输出轴朝外），**重量由托盘翻边承担，不靠夹紧**
4. 驱动轮装到舵机 5/6 的输出盘上（4× M3×10，注意轮子不偏心）
5. 万向球轮装在前后 Ø22 让位孔
6. 手动推车：四轮着地、无跷跷板；底盘离地约 15mm

> 为什么底盘要拆成三块：240×200 超出多数打印床（220）。三块都能单独打印，
> 也能直接拿去激光切割。连接板是**同一套 20mm 网格**，装反了也能对上。

### 9.3 合体与配重

- 电池放在底盘**后部**，抵消臂前伸的倾覆力矩
- 整机重心投影必须落在两驱动轮连线前方 30mm 内，否则加速会点头
- 用一只手推整机侧倾，倾角 > 15° 才翻 = 合格

### 9.4 整机验收

| 项 | 标准 |
|---|---|
| 自重 | 2.0–2.5kg |
| 直立静止 | 手推侧倾 15° 不翻 |
| 全臂展末端负载 | 100g 不下垂超过 2mm/10s |
| 急停 | 断电后 0.3s 内停止（惯性滑行除外） |
