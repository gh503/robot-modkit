## 80.2 可视化 / 仿真使用地图

| **3D 实时 / 场景编辑** | `modkit simui`，四宫格 3D + JSON 编辑器；见 [56](56-工作台3D实时视图.md)、[57 ](57-场景编辑器与回归基线.md) |

## 80.3 版本说明

当前 **v1.38.1**：Pages/Docker CI、控制台入口、模型审计与可安装 wheel；
另含 v1.32 的流体材料库（15 种）、工程计算、三维世界 schema/8 个环境预设、
浅水/水箱/管道实验和 `world.html` 查看器。结构查看器支持关节滑杆/播放/爆炸视图；设计器支持复制/粘贴/
拖拽导入和 3D 问题高亮；Chrome CDP 冒烟测试进 CI。预算优化器现在能看两类候选——
省钱的，以及成本不升但更轻的（勾选“同价减重”/`--mass`）。m1 换 160 底盘成本不变、减重 80g。规划仍是
