# 39 · 视觉与抓取（M3 软件链）

> 没有相机也能把这条链跑通：合成色块图 → 检测 → 四点标定 → 桌面坐标 → 逆解 → 抓取序列。
> 真机只差"标定 + 换真实图"。

## 1. 链路

```
图像 → detect_color() → 像素中心
     → TableCalib（四点仿射）→ 桌面 mm
     → plan_pick() → 上方/抓取两个位姿 + 关节角
     → Robot.move_pose() / gripper() → 序列
```

代码：`software/modkit/vision.py`，CLI：`modkit vision` / `modkit --sim pick`。

## 2. 检测

- 颜色距离 ≤ tol 的像素 → 最大连通块（4 邻域，纯 numpy，不依赖 OpenCV）；
- 返回质心、面积、包围盒；
- 默认 `tol=50`、`min_area=200`；
- 合成图 40×40 方块：质心误差 <0.6px，面积 1600 精确。

```bash
modkit vision --image cube.png --target 200,60,40
```

## 3. 四点标定

`TableCalib.from_points(pixels, table_mm)` 最小二乘拟合仿射：

```
x = a·u + b·v + c
y = d·u + e·v + f
```

至少 3 点，建议 4 点覆盖工作区四角。标定结果存 JSON（`a..f`）。

```bash
modkit vision --image cube.png --target 200,60,40 --calib calib.json --plan
```

## 4. 抓取规划

`plan_pick()` 给两个位姿：

- 上方：`z = 桌面 + 60mm`
- 抓取：`z = 桌面 + 25mm`（按夹爪指长/方块高度调）

两个位姿都做逆解；够不到抛 `UnreachableError`，CLI 打印原因而不是撞限位。

## 5. 抓取序列

```bash
modkit --sim pick --image cube.png --target 200,60,40 --calib calib.json
```

顺序：上方 → 下降 → 夹爪闭合（默认 0.15）→ 抬起。当前**只允许 `--sim`**：
真机点位要先手动示教确认，避免第一次就跑飞。

## 6. 实测（合成图）

| 项 | 结果 |
|---|---|
| 40×40 方块质心 | 169.5, 119.5（真值 169.5, 119.5） |
| 两个色块选最大 | 选 1600px 的大块 |
| 异色不误检 | 通过 |
| 小噪点过滤 | 通过 |
| 仿射还原 | (50,50) → (60,70) |
| 抓取逆解回代 | x/y/z 误差 <0.5mm |
| 够不到 | 抛 `UnreachableError` |

8 项测试，`tests/test_vision.py`。

## 7. 还没做的（真机相关）

- **相机内参/畸变**：现在只做平面仿射，镜头畸变大会偏；真机建议先做棋盘格校正；
- **光照**：固定阈值在暖光/阴影下会漂，需要白平衡或 HSV 阈值；
- **深度**：单目俯视假设桌面平整、方块高度已知；
- **抓取反馈**：没有"夹住没有"的检测（可用电流/堵转或第二次拍照）；
- **手眼标定**：相机装在臂上还是架子上，变换矩阵还没做。

这些都需要相机和真机，先标为**硬件阻塞**；软件接口已经留好（`TableCalib`、`plan_pick`）。
