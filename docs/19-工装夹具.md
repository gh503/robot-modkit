# 19 · 工装夹具

> 装得正不正，不该靠手感。三件套都是 30 分钟能打完的小件，
> 但它们把"每次装得差不多"变成"每次装得一样"。

## 1. 三件套

| 夹具 | 解决什么 | 关键尺寸 | 打印 |
|---|---|---|---|
| `insert_guide` | 热熔铜螺母压歪、压深不一致 | 导向孔 Ø4.6，顶部让位 Ø9×6 | 42 g / 1.2 h |
| `jaw_block` | 夹爪开口调到 40mm 全凭眼看 | 40.0 × 26 × 8（带手柄） | 10 g / 0.4 h |
| `cradle` | 底盘平放时接不了线，立起来又滑 | 66° V 槽，100×58×60 | 41 g / 1.9 h |

合计约 **93 g / 3.7 小时**，一套就够，不用每台都打。

文件：`cad/out/{insert_guide,jaw_block,cradle}.{step,stl}`，由 `cad/jigs.py` 生成。

## 2. 怎么用

### 2.1 热熔螺母（insert_guide）

1. 把夹具平放在桌面，孔对准打印件上的 Ø4.2 底孔；
2. 铜螺母从顶部 Ø9 让位孔放入，花键朝下；
3. 烙铁 280–300℃ 顶住螺母，**垂直**下压到与夹具上表面齐平（夹具就是深度基准）；
4. 冷却 30 秒再移开夹具；侧向观察窗能看到螺母有没有歪。

为什么需要：手压时 3–5° 的倾斜很常见，倾斜的螺母会让螺丝受力偏，长期会拉裂打印件。

### 2.2 夹爪开口（jaw_block）

1. 夹爪装好后先不要通电；
2. 把 40mm 方块塞进两爪之间，让爪尖轻贴方块两侧；
3. 拧紧动爪与输出盘的 4 颗 M3；
4. 抽出方块，手动开合确认不刮。

对应参数 `P.JAW_GAP_OPEN = 40.0`；改参数后方块也要重打（`jigs.py` 会自动跟着变）。

### 2.3 底盘接线（cradle）

1. 底盘侧边卡进 V 槽（66°），重心落在槽底；
2. 背面朝上，接线/贴线束卡扣；
3. 两个 cradle 一组更稳（前后各一个）。

## 3. 打印参数

| 项 | 值 | 原因 |
|---|---|---|
| 材料 | PETG | 夹具要反复用，PLA 会蠕变 |
| 层高 | 0.2 | 通用 |
| 壁数 | 4 | 导向孔要耐磨 |
| 填充 | 25% | 比零件高，夹具要抗压 |
| 支撑 | 不需要 | 三个件都是"躺平"姿态 |
| 热床 | 80℃ + 胶棒 | 大面积底面防翘 |

## 4. 验收

- [ ] `insert_guide`：Ø4.6 孔能轻松穿过 M3 螺丝，螺母放入不晃
- [ ] `jaw_block`：卡尺量宽度 40.0 ±0.1
- [ ] `cradle`：底盘放进去不左右晃，V 槽不刮伤件
- [ ] 三件都不翘（平板玻璃上间隙 <0.5mm）

## 5. 自检（CI 会跑）

```bash
cd cad && ../.venv/bin/python jigs.py
```

输出：三件尺寸/体积 + 两条硬断言（能进打印床、jaw_block 宽度 == `JAW_GAP_OPEN`）。
`build.py` 里也加了 6 项夹具检查（可打印 + 实体有效），总数 **85 项**。
