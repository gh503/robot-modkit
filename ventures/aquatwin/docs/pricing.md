# AquaTwin 定价与 ROI 说明

> 价格是**示例**，不是报价；实际按客户工资/电价/服务价/池型重新算。
> 任何“节省 X%”必须附基线、样本、时间窗。

## 1. 价值锚点

客户单次人工成本：

```
人工 = 工时 × 工资 + 化学品 + 空驶/补人
```

AquaTwin 输出机器人单次成本（运行+折旧），差额就是“可分享的节省”。

以示例场景：

| 项 | 值 |
|---|---:|
| 人工/次 | ¥110 |
| 机器人运行/次 | ¥24.3 |
| 机器人含折旧/次 | ¥32.0 |
| 节省/次 | ¥85.7 |
| 年清洁次数 | 260 |
| 年节省/池 | ≈¥22,300 |
| 设备价 | ¥6,000 |
| 简单回收 | 3.2 月 |

**抽成定价**：客户年节省 × 10–20%，即 ¥2,230–4,460/池/年；折合
¥186–372/月/池。若按路线（30 池）打包，¥999–2,999/月。

## 2. 套餐（示例）

## 3. ROI 计算（客户版）

```
年节省 = (人工/次 − 机器人运行/次) × 年清洁次数
回收期(月) = 设备价 / (年节省 / 12)
净收益 = 年节省 − AquaTwin 年费 − 维护/耗材
```

注意：

- 不含空驶、补人、失败重洗、停机、培训、保险；
- 电池衰减/过滤器更换会抬高运行成本；
- 商业池的化学品/水质合规另算；
- 若机器人利用率低（<3 次/周），回收期显著变长。

## 4. 折扣/合同

- 年付 9 折；3 年 8 折；
- 试点期 50% 折扣，换数据授权；
- OEM 按出货量阶梯；
- 不承诺“省 X%”；合同写“决策支持”，不写性能保证。

## 5. 定价验证

- 20 个服务商访谈：愿意为“报价依据”付多少？
- 3 个试点：A/B 报价（有/无报告）中标率；
- 追踪：报告使用率、续费、NPS；
- 如果客户只为“报告”付 ¥299，不为订阅付费，说明价值在获客而非运营，应改按次/按标定收费。
