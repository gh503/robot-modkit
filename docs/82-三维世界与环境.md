# 82 · 三维世界与环境

> 状态：**v1.35.0 schema v2 已实现**。目标：用一份可校验的 JSON 描述“现实房间/水池/管道/温室”，
> 让机器人、流体、传感器和实验在同一个坐标框架里复现；浏览器可看、可改、可导入导出。
> 不是照片级渲染，也不是完整刚体/流体耦合求解器；物理闸门 **0/5**。

## 82.1 坐标约定

- 右手系：**X 向前/东，Y 向左/北，Z 向上**，单位 **米**；
- 对象 `position` 是**底面中心** `[x,y,z]`；`size` 是局部 `[x,y,z]` 尺寸；
- 旋转 `[rx,ry,rz]`（度），当前查看器主要使用 `rz`（绕 Z 的 yaw）；
- 世界原点由场景定义；需要 GIS 时用 `georeference.lat/lon/alt` 记录锚点；
- Three.js 查看器转成 Y-up 渲染，JSON 本身不转——CAD/机器人/流体都用 Z-up。

> 为什么不用 Y-up：CAD、机器人 REP-103、流体高度场都习惯 Z-up；只在渲染层转换，
> 避免“导出的 JSON 在 Blender 里躺倒”。

## 82.2 世界 JSON 结构

```json
{
  "schema": "modkit.world/2",
  "name": "泳池清洗实验",
  "units": "m",
  "gravity": 9.80665,
  "environment": "pool",
  "objects": [
    {"id":"deck","type":"box","name":"池边","position":[0,0,0],
     "size":[10,6,0.1],"semantic":"floor","color":"#6b7280"}
  ],
  "fluids": [
    {"id":"water","type":"pool","fluid":"water","position":[0,0,0.1],
     "size":[8,4,1.5],"level":0.8,"temperature_c":26,"salinity_ppt":2,
     "footprint":[[-4,-2],[4,-2],[4,2],[0,2],[0,0],[-4,0]]}
  ],
  "robot": {"assembly":"assemblies/m1_pen.json","position":[4.5,0,0.1],
            "yaw_deg":0,"task":"pool_clean"},
  "sensors": [
    {"id":"level","type":"level","position":[0,0,1.5],"target":"water","unit":"m"}
  ],
  "custom_fluids": [],
  "lighting": {"sun_azimuth_deg":135,"sun_elevation_deg":55,
               "intensity":1.2,"ambient":0.45,"sky":"#0a1622"},
  "georeference": null,
  "metadata": {}
}
```

### 对象类型

| `type` | 必填 | 用途 | 查看器 |
|---|---|---|---|
| `box` | `size` 3 正数 | 地面/墙/台面/池体 | 实体 + 边线 |
| `cylinder` | `radius`,`height` | 罐/管/柱 | 圆柱；`semantic=pipe` 横放 |
| `sphere` | `radius` | 障碍/浮球 | 球 |
| `plane` | `size[0..1]` | 大地面/水面 | 平面 |
| `mesh` | `source` + `size` | 导入真实场景 OBJ | 加载 OBJ；失败红色线框 |
| `heightfield` | `source` 或 `heights` + `size` | 地形/坡面 | 按 `heights` 真实网格渲染；无数据才线框占位 |

`collider`：`box`/`mesh`/`none`；`semantic`：`floor`/`wall`/`pool`/`pool_floor`/
`pipe`/`table`/`obstacle`/`ground` 等。查看器用语义着色，求解器用语义找地面/池底。

### 流体对象

| `type` | 几何 | 体积 |
|---|---|---|
| `pool` / `reservoir` / `puddle` | `size` 长方体；可加 `footprint` | 矩形 `x*y*z*level`；多边形面积×z×level |
| `tank` | `radius/height` 或 `size` 长方体 | 圆柱/长方体 × `level` |
| `pipe` | `radius` + `height`（长度） | `πr²L*level` |
| `rain` | 预留 | 当前只做体积记账 |

`level` 是 0..1 的充填比例；`volume_m3` 可显式覆盖（用于水坑/泄漏）。
`temperature_c`/`salinity_ppt` 会被传感器和流体报告使用。

**多边形水面（v2）**：`footprint` 是**相对 `position` 的局部 XY**（中心坐标），
点按顺序给出、不自交、落在 `size[0:2]` 包围盒内；`capacity_m3` 按鞋带公式面积×
`size[2]`，`world run` 用同一个多边形生成浅水掩膜，边界不通量。
L 形示例：`world init --preset pool_l`，或 `web/data/world-pool_l.json`。

**heightfield（v2）**：`heights` 是行=y、列=x 的二维数组（米），至少 2×2；
`size[2]` 只作包围盒高度。查看器按真实高度建网格，不再画线框盒子。
`source` 与 `heights` 二选一；大网格建议后续接 PLY/glTF（尚未实现）。

### 机器人 / 传感器 / 光照

- `robot.assembly` 指向 `assemblies/*.json`；查看器画简化占位（底盘+桅杆+臂），
  不是完整 CAD；真实几何仍在 `cad/` 和 Studio。
- 传感器：`level`/`pressure`/`flow`/`temperature`/`turbidity`/`camera`/`imu`；
  `target` 指向流体 id。没有模型的传感器明确 `modeled:false`，不编数。
- 光照：方位/高度/强度/环境光/天空色；查看器用背景/雾和两盏灯。
- `georeference`：`{lat,lon,alt,rotation_deg}`，只记录锚点，不做地图投影。

## 82.4 从零创建一个世界

1. **量现实**：房间/池体的净尺寸、门槛、障碍、机器人起点；以米记录。
2. **选原点**：建议在池底中心/房间角落；Z=0 是地面。当前校验不允许对象底面低于 0；地下池体需先用地面抬高/扩展 schema。
3. **建外壳**：地面用 `box`（0.1m 厚），池体用 `box`（`semantic=pool`，半透明），
   或导入 OBJ：
   ```json
   {"id":"room","type":"mesh","position":[0,0,0],"size":[6,4,3],
    "source":"./data/room.obj","color":"#8a96a8","opacity":1.0}
   ```
4. **放水**：`pool`/`tank`/`puddle`，给 `fluid`、`level`、`temperature_c`、`salinity_ppt`。
5. **放机器人**：`assembly` 指向现有装配；`position` 是底面中心，`yaw_deg` 是朝向。
6. **加传感器**：`level`/`pressure`/`flow`；没有模型的类型标记 `modeled:false`。
7. **校验**：`world validate`；先修错误，再看 warning（无地面/无池底/georef 缺字段）。
8. **跑**：`world run --file ... --duration 5 --out out/exp`。

最小示例（2×2m 地面 + 1m³ 水箱）：

```json
{
  "schema":"modkit.world/2","name":"最小水箱","units":"m","gravity":9.80665,
  "environment":"lab",
  "objects":[{"id":"floor","type":"box","position":[0,0,0],"size":[2,2,0.1],
              "semantic":"floor","color":"#4b5563"}],
  "fluids":[{"id":"water","type":"tank","fluid":"water","position":[0,0,0.1],
             "size":[1,1,1],"level":0.7}],
  "robot":{"assembly":"assemblies/bench_joint.json","position":[0,0,0.1]}
}
```

## 82.5 浏览器查看器

```bash
cd web && python3 -m http.server 8777
# 打开 http://127.0.0.1:8777/world.html
```

功能：

- 9 个预设、导入/导出世界 JSON、JSON 编辑后即时应用；
- **对象编辑（v1.35）**：点选/下拉选对象，拖动移动，方向键微调（Shift 0.25m），
  `[`/`]` 旋转，数值面板改位置/旋转/尺寸；复制/删除/添加盒体；
- 撤销/重做 40 步；本地草稿保存/读取；`#world=<base64>` 分享链接；
- 多边形水面（`footprint`）按 ExtrudeGeometry 渲染；heightfield 按 `heights` 渲染；
- 3D 旋转/缩放/平移（拖动/滚轮/右键）；
- 流体对象选择、材料选择、液位/温度/盐度滑杆；
- 材料属性面板（密度、动力/运动粘度、表面张力、屈服应力）；
- 载入 `world run` 生成的 `frames.json`，按帧播放浅水高度场；
- OBJ 网格加载（相对页面 URL）；失败时红色线框并提示，不静默假装成功；
- 仓库自带 `web/data/world-room.json` + `room-demo.obj` 示例，可直接打开
  `world.html?world=./data/world-room.json`（6×4×3m 开放房间，演示导入，不是扫描重建）。

**注意**：查看器里的水面波动是视觉预览；只有 `world run` 的 `metrics.json` 是求解器结果。
查看器不做碰撞/动力学，不替代 `simui`/`simrun`。

## 82.6 还原现实环境的边界

- 支持**手工测量 + 长方体/圆柱/球/平面 + OBJ + 多边形水面 + 小规模 heightfield**；
  不支持照片自动重建、点云配准、SLAM 建图、语义分割；
- OBJ 只读顶点/三角面，不读材质/纹理/骨骼；大模型没有 LOD/流式加载；
- 碰撞体是元数据，查看器不做物理碰撞；刚体动力学在 `sim`/外部引擎；
- 光照是视觉，不是光学/热仿真；
- 真实世界的摩擦、回差、线缆、人物/宠物、化学腐蚀都不在模型里；
- 物理闸门仍 **0/5**。
