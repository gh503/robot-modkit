# 56 · 工作台 3D 实时视图

> 2D 俯视/侧视够调试，但空间关系要靠脑补。v1.1 在工作台加一块 3D：
> 底盘位姿、两段臂、夹爪端点、方块，20ms 跟随 `/api/state`。

## 1. 实现

- `three.js` 从仓库 `web/vendor/three.min.js` 本地加载，不依赖 CDN；
- 后端新增 `GET /vendor/three.min.js`，只服务这一个固定文件；
- 场景：120×200 底盘、两段圆柱臂（用 `arm_side` 的 3 点重建）、绿色 EE 球、红色方块；
- 每帧 `robot.position/rotation.z` 同步 `pose`，圆柱 `quaternion` 对齐关节线段；
- 方块被夹住时变绿（`held`），仍放在桌面真实坐标（不伪造"跟着夹爪飞"）。

## 2. 布局

工作台四块：俯视、侧视、3D、相机（2×2）。3D 画布 560×420，随卡片缩放。

## 3. 验证

- `node --check` 通过；
- 无头 Chrome + SwiftShader 截图，画布有底盘/臂/方块颜色；
- 页面 `#log` 无 `JS 错误`；
- `/vendor/three.min.js` 200，603KB。

## 4. 边界

- 是**示意几何**：方块底盘、圆柱连杆，不是 CAD 网格；
- 没有 OrbitControls/阴影/材质，不可拖动视角；
- 只画 2 段臂（`arm_side` 3 点），夹爪开合用颜色/端点表示；
- 3D 是调试视图，不参与物理计算。
