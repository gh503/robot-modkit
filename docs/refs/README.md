## 引用纪律

1. 只写"能从来源读到"的事实；推断一律标 `[TODO]` 或写进 `06-决策与风险.md`。
2. 来源冲突时（如工作电压 4–14V vs 12.0V），**两条都记下来**，不要挑一个好写的。
3. 更新外部资料后，在本文表格里改"核对日期"，并重跑 `build.py` 与 `make test`。
