# 21 · 批量生产

> 单台能装出来，和"10 台都一样"，是两件事。这篇管后者。

## 1. 批次怎么划

| 项 | 规则 |
|---|---|
| 批次大小 | **5–10 台**（一台打印机一周约 2 台，5 台是 2.5 周） |
| 批次号 | 与年份绑定：`M1-2026-0001` … |
| 首件 | 每批第 1 台**全检**，之后每 5 台抽 1 台做 Q3 |
| 冻结 | 批次开始后不改图纸/固件；要改就开新批次 |

序列号规则：`M1-<年份>-<4 位序号>`，唯一且**不可复用**（报废的号也留着）。

## 2. 生产节拍（单台）

| 工序 | 时间 | 备注 |
|---|---:|---|
| 打印 | 14.3 h | 机时不占人；可 3 台并行 |
| 打印后处理 | 1.5 h | 拆支撑/修孔/压螺母 |
| 机械装配 | 3.0 h | 按 [05](05-装配手册.md) |
| 接线 | 1.0 h | 按 [03](03-配电与线束.md) |
| 烧录 + 标定 | 1.0 h | 见 §4、§5 |
| 质检 + 包装 | 0.5 h | 按 [18](18-质检与验收.md) |
| **人工合计** | **7.0 h** | 与 `hardware/bom.json` 一致 |

10 台批次：约 **70 人时 + 143 打印机时**；两台打印机两周可以完成。

## 3. 工位与工具

| 工位 | 需要 | 产出 |
|---|---|---|
| 打印区 | 打印机 ×2、PETG、铲刀、剪钳 | 零件 + 工装 |
| 装配区 | M3 螺丝刀（0.4N·m 扭力批）、镊子、热熔螺母烙铁 | 机械半成品 |
| 电气区 | 万用表、剥线钳、压线钳、热风枪 | 线束 + 电控 |
| 测试区 | 12V 电源、USB 线、砝码（100g/200g）、卡尺、红外测温枪 | 记录 + `bench-*.csv` |

工装三件套（[19](19-工装夹具.md)）每批只需打一套，放装配区公用。

## 4. 固件烧录

```bash
# 1) 确认工具链
./tools/arduino-cli version

# 2) 编译（记录固件版本）
cd firmware/esp32 && ../../tools/arduino-cli compile --fqbn esp32:esp32:esp32s3 modkit_esp32

# 3) 逐台烧录（插上 USB 后）
../../tools/arduino-cli upload --fqbn esp32:esp32:esp32s3 -p /dev/ttyACM0 modkit_esp32
```

要求：
- 每台的固件版本写进记录（`firmware_version`）；
- 烧录后跑一次自检（`modkit --port ... scan`），6 个 ID 全在才算过；
- **不要**在批次中途换固件版本；要换就整批换并重测首件。

## 5. 标定（每台必做）

```bash
modkit calib --port /dev/ttyUSB0 --action scan
modkit calib --action limits --id 1 --lo 0 --hi 180      # 每个关节
modkit calib --action zero  --id 1 --name yaw --deg 90 --save calibration-M1-2026-0001.json
modkit calib --action verify --file calibration-M1-2026-0001.json --tol 2
```

标定文件命名跟序列号走，存档并把 **sha256** 填进质检记录。

## 6. 质检记录

```bash
# 建记录（自动取下一个号）
modkit qc --action new --operator 老王 --dir records

# 现场逐项改 ok，填 Q3 数据，然后校验
modkit qc --action validate records/M1-2026-0001.json

# 整批汇总（良率）
modkit qc --action summary records/*.json
```

判据写在代码里（`software/modkit/qc.py`）：
抓放 ≥8/10、重复精度 ≤2mm、温升 <55℃、缺标定指纹或固件版本 → 不能判合格。

## 7. 抽检与放行

- 首件：Q1+Q2+Q3 全做；
- 后续：Q1 全检（便宜），Q2 全检（装完就知道），Q3 每 5 台抽 1；
- 抽检不合格 → **整批回查 Q3**，并记录批次号；
- 放行条件：本批记录 `validate` 全过 + 抽检合格。

良率目标：首批 ≥80%，稳定后 ≥95%。低于 70% 停下来查工艺，不要靠返修补。

## 8. 包装与出货

| 件 | 要求 |
|---|---|
| 主机 | 气泡膜 + 珍珠棉，夹爪处加固定块（防止运输中受力） |
| 电池 | 单独绝缘袋，电量 30–50% |
| 配件 | 螺丝包、备用保险丝、USB 线、快速开始卡 |
| 文档 | 二维码指向 [07 手册](07-小白操作手册.md) + 本批标定文件 |

## 9. 返修与备件

- 备件率按 8% 计（`hardware/bom.json` 的 `scrap_rate`）；
- 返修记录写在同一个 `records/<serial>.json` 的 `notes` 里，**不新建号**；
- 返修后必须重跑 Q3 并更新 `conclusion`；
- 舵机是唯一易损件，建议每批多买 1 只。

## 10. 还没做的

- 没有生产管理系统（MES），靠 `records/*.json` + git 管；
- 没有夹具级防错（Poka-yoke），装反仍靠人看；
- 没有自动化测试台（重复精度靠手量）；
- 包装没有跌落测试数据。
