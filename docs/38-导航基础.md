# 38 · 导航基础（M2 第一步）

> 里程计标定（[29](29-里程计标定.md)）解决"我走了多远"；这一篇解决"我怎么走到那个点"。
> 先做**纯控制器 + 理想单轮车**：没有硬件也能把边界跑完，真机只差一层轮速下发。

## 1. 控制器

`software/modkit/nav.py`，输入当前位姿 `(x, y, θ)` 和目标位姿，输出 `(v, ω)`：

1. 位置误差 <8mm 且朝向误差 <3° → 停；
2. 位置到了但朝向不对 → 原地转；
3. 朝向差 >50° → 原地转（避免画大弧）；
4. 否则边走边修：`v = v_max · min(1, dist/120) · cos(方位误差)`，`ω = k·方位误差`。

默认：`v_max=150mm/s`、`ω_max=90°/s`、`k_rot=2.5`、`k_lat=2.0`。

## 2. 仿真结果

```bash
modkit nav --path square --size 300
```

| 段 | 目标 (mm,°) | 用时 | 终点误差 | 朝向误差 |
|---|---|---:|---:|---:|
| 1 | (300, 0, 0) | 3.1s | 7.9mm | 0.0° |
| 2 | (300, 300, 90) | 4.6s | 8.0mm | 2.9° |
| 3 | (0, 300, 180) | 4.6s | 7.7mm | 2.9° |
| 4 | (0, 0, 270) | 4.6s | 7.6mm | 2.9° |

方形闭环回到起点 **7.6mm** 内，总耗时约 17s。判据：每段 ≤12mm / ≤5°，否则命令退出码 1。

直线单点：

```bash
modkit nav --path line --size 500
```

## 3. 真机怎么接

控制器输出的是 `v`（mm/s）、`ω`（°/s），换算成左右轮线速度：

```python
from modkit import kinematics as kin, nav
left, right = kin.wheel_speeds(v, w, kin.DriveGeometry())
```

再写进舵机速度寄存器（`0x2E`，最高位方向）。当前 CLI 只做仿真，**没有**下发轮速；
下一步是加 `modkit drive --left --right` 并用 [29](29-里程计标定.md) 的轮径/轮距闭环。

## 4. 现在没做的

- 没有定位：位姿来自里程计，走久会漂（需要视觉/二维码/激光）；
- 没有避障、没有速度平滑（加速度突变会让轮子打滑）；
- 没有打滑检测；
- 理想模型里 `v` 立即生效，真机有加减速和死区。

## 5. 验收

| 项 | 判据 | 结果 |

| 直线 300mm | 终点 ≤10mm，横向 ≤1mm | 7.9mm / 0.0mm |
