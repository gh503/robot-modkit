## 3. 替代方案（如果 1 号缺货或涨价）

| 替代 | 价格 | 代价 |
|---|---|---|
| 幻尔 LX-16A | ¥70–90 | 便宜，但协议/力矩曲线资料少，社区案例少 |
| 飞特 STS3215（7.4V 版 C001） | ¥95–110 | 必须换 2S 锂电方案，电源部分要重做 |
| 达秒/其他国产串行舵机 | ¥60–80 | 便宜，但"总线 + 独立 ID + 位置反馈"三件不一定齐，**缺一就不要** |

> **不可妥协的三条**：串行总线、菊花链、每个舵机有独立 ID 和位置反馈。
> 少了任何一条，这套模块化架构就退回"PWM 舵机 + 一堆线"，拆装一次就要重新接线。

## 4. 明确不买（这一阶段）

| 不买 | 为什么 |
|---|---|
| 锂电池 + BMS + 充电器 | ¥300+，台面调试用适配器完全够；等到要做移动构型再上 |
| Dynamixel X 系列 | 单个 ¥600+，是这台整机的预算 |
| 树莓派 / Jetson | 没有视觉需求前是纯负担；ESP32 + 电脑足够 |
| IMU / 力矩传感器 | v0.1 的验收标准里没有闭环控制，装了也用不上 |
| 3D 打印机 | 除非你本来就想要；代打一批 ¥70 更快 |
| KiCad 定制 PCB | 4 个舵机的配电用端子排就够，画板子是把时间花在错误的地方 |
