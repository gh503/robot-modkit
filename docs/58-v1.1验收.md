## 4. 边界（新增部分）

- 畸变只到 k1/k2/p1/p2，无鱼眼/rolling shutter；内参仍是给定值；
- 手眼是平面相似变换，无深度/倾角；标定点是仿真真值，真机要 RANSAC；
- 接触无转动/变形/压力分布；μs/μk/刚度需实测；
- 3D 是示意几何，无 OrbitControls/阴影；
- 排板是 2D 包围盒，不处理支撑/翘曲；4 张/套是当前几何的诚实结果；
- 编辑器保存只校验 `actions` 存在，不做完整 schema。
