# 33 · 回差与消隙

> 蒙特卡洛说开环末端 95% 误差 6.24mm（[32](32-公差蒙特卡洛.md)），主因是**关节间隙/回差**。
> 消隙垫片是机械解法，换向补偿是软件解法，两个都便宜。

## 1. 先量：回差有多大

```bash
modkit --port /dev/ttyUSB0 backlash --action measure --id 1 --span 10 --settle 0.35
```

做法：先到 `center+10°`，慢速回到 `center` 读一次；再到 `center-10°`，慢速回 `center` 读一次。
两个读数之差 = 回差（含齿轮背隙 + 联轴器间隙）。

判据：

| 回差 | 结论 |
|---|---|
| <0.5° | 好 |
| 0.5–1.0° | 可接受，建议补偿 |
| >1.0° | 先查机械（输出盘螺丝松、舵盘花键磨损） |

六个关节都量一遍，结果写 `backlash.json`（`{ "1": 0.8, "2": 0.6, ... }`）。

## 2. 再补：换向时多走半个回差

```python
from modkit.backlash import Compensator
comp = Compensator(); comp.load("backlash.json")

cmd = comp.command(1, target_deg)   # 按上次方向自动 ±play/2
robot.goto(1, cmd)
comp.note(1, target_deg)            # 记录"想去哪"，不是"到哪"
```

原理：换向时先空走 `play/2` 把齿面贴合，再走剩下的；误差从 `play` 降到约 `play/2`。
**不要**把补偿后的角度当成实际角度记进标定。

## 3. 机械消隙（更彻底）

| 方法 | 成本 | 效果 | 难度 |
|---|---|---|---|
| 输出盘加 0.1mm 垫片预紧 | ¥0 | 回差 ↓30–50% | 低 |
| 换金属舵盘 + 螺丝胶 | ¥15/关节 | 消除花键间隙 | 低 |
| 偏心张紧轴承 | ¥25/关节 | 回差 <0.2° | 中 |
| 换低回差舵机 | ¥180/只 | 出厂 <0.3° | 低（贵） |

顺序：**先量 → 垫片 → 补偿 → 再考虑换件**。

## 4. 预期收益

| 项 | 补偿前 | 补偿后（估） |
|---|---:|---:|
| 单关节回差 | 0.8° | 0.4° |
| 末端 p95（[32](32-公差蒙特卡洛.md)） | 6.24mm | ~3.5mm |
| 抓取成功率 | — | 明显提升（尤其换向抓放） |

真要 <2mm：必须闭环（视觉/外部编码器），补偿只能减一半。

## 5. 代码与测试

- `software/modkit/backlash.py`：`measure()`、`Compensator`（方向判断 + 半回差）
- 6 项测试：双侧测量、span 非法、阈值、首次不补偿、正反向 ±0.5、存取
- 注意：`command()` 只算下发角，**必须**再调 `note()` 记录目标角

## 6. 局限

- 只补"可重复的回差"，补不了随机间隙（磨损后会变）；
- 大幅换向（>90°）时半回差补偿可能不够，需要实测标定曲线；
- 没有做温度/负载对回差的影响。
