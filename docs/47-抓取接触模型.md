# 47 · 抓取接触模型

> v0.8.1 起，"夹爪闭上"不再等于"抓住"。先过摩擦锥，再谈抬升。

## 1. 模型

`contact.py` 只回答一件事：两侧摩擦上限能不能扛住方块。

```
摩擦上限  F = 2 · μ · N
所需力    R = m · √(g² + a²) · safety
抓住条件  F ≥ R
```

| 参数 | 默认 | 依据 |
|---|---|---|
| 方块质量 `m` | 0.05 kg | 40mm PLA 实心约 45g |
| 摩擦系数 `μ` | 0.40 | 橡胶爪 ↔ PLA，估算 |
| 单侧夹紧力 `N` | 4.0 N | 舵机夹紧力估算 |
| 安全系数 | 1.5 | 抗加速度/振动 |
| 方块边长 | 40mm | 标称方块 |
| 夹爪开口 | 42mm | 有效开口，超过就夹不住 |

默认：`F=3.2N`，`R=0.74N`，能抓住。
`μ=0.05`（油污/光滑面）：`F=0.40N < 0.74N`，静止都夹不住 → 滑落。
60mm 方块 > 42mm 开口：几何就不成立，先判 `fits()`，再谈摩擦。

## 2. 用在哪

| 位置 | 行为 |
|---|---|
| `scenario.py` 的 `mission` | 闭合后算摩擦锥；不够就 `抓取滑落`，任务失败 |
| `simserver.py` 工作台 | 闭合且靠近 + 摩擦够才吸附；不够显示"滑落" |
| `slippery_cube.json` | 期望失败场景，断言 `mission.success=false` |
| `big_cube.json` | 60mm 方块超开口，期望失败 |

场景可以覆盖参数：

```json
{"cmd":"mission", "mu":0.05, "grip_force":4.0, "cube_mass":0.05, ...}
```

工作台右侧有"摩擦 μ"滑杆，拖动即可看夹持状态变化。

## 3. 验证

```bash
modkit simrun --scenario sim/scenarios/slippery_cube.json
# [1] grasp 摩擦 0.40N / 需要 0.74N
# [1] 抓取滑落（μ=0.05）
# [1] mission False ... 抓取失败
# 1/1 通过（expect_fail）
```

6 项 `test_contact.py` + 2 项期望失败场景。

## 4. 还不是什么

- 没有接触变形、没有夹爪行程与方块尺寸的几何约束；
- 没有滑动过程的动力学（只判"掉/不掉"）；
- 没有六维力/力矩，倾斜抓取只按最坏方向算；
- μ 和夹紧力是估算，真机要用拉力计/斜坡法标定（docs/18 Q2）。
