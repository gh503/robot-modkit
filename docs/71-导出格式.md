# 71 · 导出格式：STL / 3MF / GLB / 打印页 / STEP

> 状态：**v1.19.0 已实现**。入口：Studio →“导出”标签。

## 71.1 一份网格，四种用途

| 格式 | 坐标系/单位 | 用途 | 限制 |
|---|---|---|---|
| **STL** | Z-up / mm | CAD 参考、干涉检查、通用打印 | 无颜色/对象名 |
| **3MF** | Z-up / mm | 切片器直接打印 | 单对象、无颜色 |
| **GLB** | Y-up / m | Blender/Three/AR/Web 预览 | 视觉网格，不是 B-Rep |
| **打印页** | — | BOM + 汇总 + 校验问题，浏览器“另存 PDF” | 中文靠系统字体 |
| **STEP ZIP** | 单件原始 CAD | 改参数/重做 | 仍需 `make components-cad` 重建 |

关键区别：**STL/3MF/GLB 都是装配视觉网格**，不是参数化 STEP 实体。要改尺寸，仍导出 JSON
→ `modkit assemble plan` → `make components-cad`。

## 71.2 实现

- `forEachTriangle()` 遍历 `view.root` 的 Mesh，应用 `matrixWorld`，统一取出世界坐标/法线。
- **GLB**：
  - 按材质颜色分 primitive；位置 `(x,z,-y)*0.001` 转 Y-up 米制；
  - 手写 glTF 2.0 JSON + BIN chunk，不依赖 GLTFExporter；
  - 14 个 primitive、14 个材质；m1 约 223KB。
- **3MF**：
  - 一个 `<object>` + 顶点/三角形 XML，unit=millimeter；
  - 手写最小 ZIP store（local header + central directory + EOCD + CRC32）；
  - m1 约 428KB，Python `zipfile`/ElementTree 可正常解析。
- **打印页**：`buildPrintHTML()` 生成内联 CSS 的 BOM/汇总/问题页；
  `window.print()` 由用户另存 PDF，避免引入 PDF 字体库。
- **离线 STEP**：Service Worker 预缓存 36 个 `models/*.step`（约 2.7MB），
  断网也能导出全部零件 ZIP；代价是首次安装多下载 2.7MB。

## 71.3 验证

- 浏览器实测 m1：GLB `glTF`/version 2/228672 字节；3MF ZIP 头 `PK\x03\x04`/438189 字节。
- Python 解 3MF：ZIP 无损坏，`3D/3dmodel.model` 为 millimeter，7764 顶点/2588 三角形。
- GLB JSON：14 primitive、14 材质、BIN 217392 字节。
- `make web-smoke` 新增“导出 GLB/3MF/打印页”和 STEP 预缓存断言（9 组）。
- 总计 **310 项** pytest。

## 71.4 边界

- 3MF/GLB 不含纹理、颜色贴图、动画、装配约束；只是几何。
- GLB 转 Y-up 米制；STL/3MF 保持 Z-up 毫米——导入时注意单位。
- 物理闸门仍 **0/5**；导出格式不代表可制造性/强度验证。
