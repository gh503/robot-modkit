# AquaTwin 研究计划：从“能算”到“算得准”

> 当前 0.1.0 只验证了软件闭环（覆盖/时间/能耗/成本），**没有实测**。
> 本文定义下一阶段的假设、实验矩阵、仪器、判据与发表计划。
> 没有通过判据之前，对外只能写“modeled / 方案比较”，不能写“预测准确”。

## 1. 研究问题

1. 矩形泳池的 boustrophedon 近似，实际覆盖率误差多大？角落/台阶/深水区如何补？
2. 机器人阻力 `F=½ρCdAv²` 在泳池壁面/水流下，`Cd` 如何随姿态/速度变化？
3. 泵功率 `ρgQH/η` 在过滤器堵塞时如何漂移？压升-流量曲线能否用 2 参数模型？
4. 电池可用容量/补电时间对总工时的贡献，是否被低估？
5. 单次成本/回收期对工资、电价、路线密度的敏感性，哪个变量决定客户决策？
6. 同一模型迁移到商业池/海水/养殖池，需要哪些新参数？

## 2. 假设（可证伪）

| # | 假设 | 证伪方式 |
|---|---|---|
| H1 | 覆盖率可用 lane 几何近似，误差 ≤5pp | 染料/相机真值对比 |
| H2 | 阻力系数在 0.1–0.5 m/s 近似常数 | 拖曳力/电流实测 |
| H3 | 泵功率可用固定扬程/效率近似，误差 ≤20% | 功率计+流量计 |
| H4 | 过滤压升与捕集量线性 | 多池压升-时间曲线 |
| H5 | 客户决策主要由人工节省驱动，不是电费 | 访谈/定价测试 |

## 3. 实验矩阵

### 3.1 池型

| 维度 | 水平 |
|---|---|
| 尺寸 | 6×3、8×4、12×5、25×10 m |
| 深度 | 1.2、1.5、2.0 m |
| 形状 | 矩形；L 型/斜角（二期） |
| 水质 | 淡水 24/28°C；海水 3ppt；高盐 35ppt |
| 污染 | 低/中/高（叶/沙/藻；用 g/m³ 或浊度） |

### 3.2 机器人

| 维度 | 水平 |
|---|---|
| 清洁宽度 | 0.35/0.45/0.60 m |
| 速度 | 0.15/0.25/0.35 m/s |
| 泵流量 | 0.6/0.8/1.5 L/s |
| 电池 | 60/90/180 Wh |
| 驱动 | 履带/轮式/无刷泵 |

### 3.3 最少实验数

- 3 池型 × 3 机器人 × 3 污染 = 27 次；每组合重复 3 次 → **81 次清洁**；
- 另加 10 次海水/高盐；总计约 **91 次**；
- 每次记录：时间、能耗、覆盖率、过滤压升、流量、水温/盐度、异常/补人。

## 5. 分析

- **误差**：MAPE / 偏差 / 90% 区间；分池型/机器人报告，不只给总体平均；
- **校准**：先用 70% 数据拟合 `Cd`、泵效率、过滤压升系数，30% 留出验证；
- **不确定性**：输入分布（尺寸/污染/工资）蒙特卡洛，输出 P10/P50/P90；
- **消融**：去掉补电/过滤/阻力项，看哪项最影响误差；
- **可解释**：每个预测拆成时间/能耗/成本分项，客户能问“为什么”。

## 6. 判据（Go/No-Go）

| 指标 | 目标 | 未达标动作 |
|---|---|---|
| 时间 MAPE | ≤20% | 加补人/空驶项；分池型建模 |
| 能耗 MAPE | ≤20% | 校准泵/驱动效率；加电池老化 |
| 覆盖率误差 | ≤5pp | 改路径/加角落策略；相机真值 |
| 压升误差 | ≤5 kPa | 改过滤模型；加流量修正 |
| 客户愿意付费 | ≥3 家 | 回到访谈，别加功能 |

达不到就**不对外承诺精度**；报告继续标“modeled”。

## 7. 与 modkit 的关系

- modkit 提供：世界 schema/预设、流体材料与工程公式、浅水/水箱/管道；
- AquaTwin 提供：覆盖路径、清洁时间/能耗/过滤/经济、商业报告；
- 二期可把 AquaTwin 的场景导出为 `modkit.world/1`，用 `world run` 做流场/水位，
  再把结果回填经济模型；
- 三期可接 CFD/SPH/实机遥测；但不为了“技术先进”而上，先用实测判据。

## 8. 发表/可信度

- 公开技术白皮书：模型、假设、误差、失败案例；
- 不公开客户池地址/个人信息；
- 代码/场景可复现；数据脱敏后给研究合作方；
- 任何“节省 X%”必须给基线、样本量、时间窗、测量方法。

## 9. 风险与伦理

- 安全：机器人电气/溺水/化学品由现场持证人员负责；软件不替代安全规程；
- 隐私：水下相机可能拍到人/邻居；默认不采集，采集需授权/遮挡；
- 责任：报告是决策支持，不是性能保证；合同写明模型边界；
- 环境：反冲洗水/化学品按当地法规处理。
