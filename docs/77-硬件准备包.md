# 77 · 硬件准备包

> 状态：**v1.25.0 已实现**。目标：装配图一旦定下，就能生成一份可打印的
> “买什么、怎么装、怎么接线、上电先测什么、什么算过”的包。
> 仍然**不代替实测**；物理闸门 0/5。

## 77.1 一条命令

```bash
cd software
../.venv/bin/python -m modkit.cli assemble pack ../assemblies/m1_pen.json \
  --out ../out/pack-m1-pen
```

没有硬件也能生成；它只读装配图、组件库和 BOM，不发任何串口/运动指令。

## 77.2 生成物

| 文件 | 内容 |
|---|---|
| `README.md` | 阶段、组件/舵机数、质量、BOM/落地价、文件索引、建议顺序 |
| `bringup.md` | 上电前 → 只读扫描 → 回中/方向 → 逐关节标定 → 急停 → 轮子/直线/转向 → 工作空间 → 任务 → 烤机 |
| `wiring.md` | 12V/GND/急停/5V/舵机总线/USB/电池采样；上电顺序；ID 表 |
| `assembly-steps.md` | 按父子深度排序的装配步骤、检查项、工具、预计时间 |
| `print.md` | 打印/自制件数量、单件/合计克重、BOM 小计 |
| `acceptance.md` / `.csv` | 验收矩阵；初始全部 `pending` |
| `firmware.json` | 板型、波特率、引脚、舵机 ID→实例/关节、safety/calibration 引用 |
| `bom.csv` / `safety.json` / `calibration.template.json` | 复用 `assemble plan` 的输出 |
| `pack.json` | 机器可读汇总 + 假设 + 文件路径 |

`bringup.md` 的每一步都有：动作、命令、通过标准、证据、**停止条件**。
`acceptance.csv` 的每一行都有 `pending`，只有实测证据才能改。

## 77.3 阶段识别

不靠文件名，按装配实际能力分类：

| 能力 | 阶段 | 例子 | bring-up 步骤 | 验收项 |
|---|---|---|---:|---:|
| 0/1 个位置关节，无驱动 | `joint` | `bench_joint` | 6 | 6 |
| ≥2 位置关节，无驱动 | `arm` | `bench_arm` | 9 | 8 |
| 有驱动，无位置关节 | `drive` | `rover_base` | 8 | 8 |
| 驱动 + 笔 | `mobile-draw` | `m1_pen` | 12 | 11 |
| 驱动 + 夹爪 | `mobile-pick` | `m1_budget` / `m1` | 13 | 11 |
| 其他 | `assembly` | 自定义 | 按能力 | 按能力 |

## 77.4 接线与固件

- 引脚按当前 ESP32 固件：`TX=17`、`RX=16`、`DIR=4`、`VBAT=5`、`1Mbps`；
  换板必须查原理图。
- 总线按 ID 菊花链；`m1_pen` 是 `1,2,4,5`，**允许跳号**（ID 3 没装夹爪）。
- `firmware.json` 只给配置/映射，不生成 `.ino`；避免和手改固件冲突。
- `safety.json` / `calibration.template.json` 是设计值，`calibrated: false`；
  第一次上电必须按实物标定。

## 77.5 验收规则

| 编号 | 阶段 | 关键通过标准 |
|---|---|---|
| A1 | 上电前 | 极性/短路/保险/急停常闭 |
| A2 | 只读 | 设计 ID 全在；允许跳号；无故障位 |
| A3 | 只读 | 11.0–12.6V；<45℃；故障 0 |
| A4 | 单轴 | 方向正确、不顶限位、回中 ≤1.5° |
| A5 | 安全 | 急停 <0.3s；连续 3 次 |
| A6/A7 | 底盘 | 直线 1m 偏差 <30mm；转 90° 误差 <3° |
| A8/A9 | 机械臂 | 工作空间无碰撞；重复 ≤2mm |
| A10 | 任务 | 画 240° 圆弧 ≤3mm / 抓放 ≥8/10 |
| A11 | 烤机 | 10min 无过温/丢步/重启 |

## 77.6 边界

- 线束是**逻辑接线/检查表**，不是按长度下料的线束图；线长/端子/压接要实物确认。
- 打印克重来自 BOM 估算，不含支撑/失败重打；打印参数见 `docs/31`。
- 装配时间是设计估算，不是实测工时。
- 限位/零位/方向是设计值；第一次上电以实物为准。
- 不替代 CAD 干涉、电气安规、EMC、真实动力学。
- 物理闸门仍 **0/5**。
