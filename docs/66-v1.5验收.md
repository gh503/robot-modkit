## 66.1 本版交付

1. **组件注册表** `software/modkit/components.py`：
   36 个组件、9 个类别、统一 `Port/Component/BomItem/PowerSpec/JointSpec/ToolSpec`，
   4×4 刚体变换与公母/网格配对规则。

   JSON 读入、父子/端口求解、网格 20mm、端口复用、环、舵机 ID/控制器容量、
   BOM、功率、重心/支撑、关节静载、AABB 碰撞、安全配置/标定模板。

   `modkit components [list|show|check]`；
   `modkit assemble [validate|plan|preview]`。
4. **6 个可跑装配示例**：`assemblies/*.json`。
5. **参数化 CAD**：`cad/component_cad.py`，36 个组件 STEP/STL + manifest；
   `make components-cad`。
6. **测试**：新增 27 项；软件测试 **234 → 261**。
7. **文档**：[65 组件库与自由组装](65-组件库与自由组装.md)、本篇；

## 66.4 本版明确没有做

- 没买/打印/装配/上电/标定；**物理 0/5**。
- 没做关节运动后的碰撞/重心/线缆干涉；只校验装配零位。
- 没做网格级碰撞；AABB 会误报/漏报。
- 没做动力学、摩擦、回差、热、寿命、抓取力实测。
- `m1.json` 是组件库的**同轴塔式**装配，不是原 M1 CAD 的水平关节臂；
  两者几何/运动学不能互相冒充。
- 质量/BOM 是估算，不是供应商报价；示例 M1 的 1854g 与 [01](01-系统设计.md)
  约 2.2kg 同量级，但口径不同。
- 没有把 `assembly` 接到查看器/仿真运动学；`safety.json` 只解决关节限位配置。
