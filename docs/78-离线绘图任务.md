# 78 · 离线绘图任务

> 状态：**v1.26.0 已实现**。目标：买回阶段 1/3 后，不用手写坐标就能验证
> “按路径动、限位不撞、能画出可测量的轨迹”。先离线生成 CSV/SVG，再仿真回放，
> 最后才真机。不控制抬笔/落笔，不替代标定。

## 78.1 两种运动学，别混

| 模式 | 关节 | 能画什么 | 例子 |
|---|---|---|---|
| `arm` | yaw + shoulder + elbow | 平面任意折线/方/圆/三角 | `bench_arm` |
| `polar` | yaw + shoulder，固定上臂 | **固定半径圆弧**（yaw ±120°） | `m1_pen` |

`m1_pen` 只有两个位置关节，末端在固定半径球面上；纸面水平时只能画圆弧，
**不能画方框/写字**。要画任意平面路径，需要第三个关节（肘）或移动底盘协同。
这是设计边界，不是软件限制。

## 78.2 生成路径

```bash
cd software
# 3DOF 桌面臂：100mm 方框（腕点 z=150，笔尖再向下 60mm）
../.venv/bin/python -m modkit.cli draw --shape square --size 100 --z 150 \
  --out ../out/draw-square.csv --svg ../out/draw-square.svg

# 3DOF 圆 / 三角 / 直线
../.venv/bin/python -m modkit.cli draw --shape circle --radius 45 --z 150 --out circle.csv
../.venv/bin/python -m modkit.cli draw --shape triangle --size 90 --z 150 --out tri.csv

# m1_pen 2DOF：240° 圆弧（名义上臂 175mm，半径 150mm）
../.venv/bin/python -m modkit.cli draw --shape arc --mode polar --radius 150 \
  --sweep 240 --l1 175 --out ../out/arc.csv --svg ../out/arc.svg
```

输出：

- `draw.csv`：`x/y/z`、`yaw/shoulder/elbow`、三轴 tick、模式；可直接对照示教器；
- `draw.svg`：俯视路径预览，标起终点；
- `stats`：点数、包围盒、路径长度、最大单步（默认警告阈值 8°）。

`z` 是**腕点**高度，不是笔尖；安全检查按 `envelope.gripper_len=60mm`
把笔尖再往下算。默认 `z=150` 对应笔尖约 90mm，避免低于桌面安全线。

## 78.3 回放

```bash
# 仿真：不需要串口，逐点走 SafetyPolicy
../.venv/bin/python -m modkit.cli draw --shape square --z 150 \
  --out /tmp/draw.csv --play --sim

# 真机：必须显式 --yes；先空载、手放急停、轮子/臂周围清空
../.venv/bin/python -m modkit.cli draw --shape square --z 150 \
  --out draw.csv --play --port /dev/ttyUSB0 --yes --calibration calibration.json
```

- 没有 `--port` 时 `--play` 默认仿真；
- 有 `--port` 时没有 `--yes` 直接拒绝；
- 每个目标都过 `SafetyPolicy.guard_motion`（电压/温度/故障/限位/单步）；
- 3DOF 还过 `Robot._assert_path` 的几何包络；
- 2DOF 没有 elbow，回放只校验实际存在的 yaw/shoulder，不伪造第三轴；
- **不会自动使能/上电**；上电、使能、急停仍按 [77](77-硬件准备包.md)。

## 78.4 测量与判定

| 项 | 方法 | 通过 |
|---|---|---|
| 方框 | 纸张四边，卡尺量边长 | 100±3mm；四角闭合 |
| 圆 | 量直径/圆度 | 半径误差 ≤3mm |
| 三角 | 三边/角度 | 边长误差 ≤3mm |
| 圆弧 | 半径/起终点 | 半径 ≤3mm；回差 ≤3mm |
| 关节 | `draw.csv` 对照实际角度 | 方向正确；不顶限位 |

失败模式：笔尖刮纸（Z 太低）、断线（速度/压力）、丢步（负载/电流）、
起终点错位（零位/回差）。先记录，不要靠调大电流硬顶。

## 78.5 边界

- `l1/l2/base_h` 是**名义几何**；实物要量上臂/前臂/笔尖偏置后传入；
- 不做笔尖 XY 偏置补偿、纸面倾斜、回差补偿；
- 不控制抬笔/落笔；连续路径从起点到终点都假定笔尖接触；
- 不移动底盘；`m1_pen` 的圆弧是静态绘图；
- 不替代标定、碰撞检查、急停；
- 物理闸门仍 **0/5**。
