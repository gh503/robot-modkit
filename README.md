# modkit —— 可拆装模块化机器人（v0.1）

> 一个"先定接口、再定形态"的模块化机器人起步套件。
> 4 个总线舵机关节 + 一套打印结构件，同一批模块能拼出机械臂和差速小车。

## 现在有什么

| 目录 | 内容 | 状态 |
|---|---|---|
| `cad/` | 参数化 CAD（build123d）+ STEP/STL 导出 + 几何自检 + 预览渲染 | 33/33 自检通过 |
| `firmware/` | FT-SCS 协议实现、总线驱动、PC 端总线仿真、单元测试 | 41/41 测试通过 |
| `docs/` | 接口规范、配电与线束、BOM、装配工艺、测试计划、决策与风险 | 已完成 v0.1 |
| `electronics/` | 配电与分线板方案（v0.1 先用端子排，不画 PCB） | 方案级 |

## 快速开始

```bash
# 1) 重新生成 CAD 并跑自检（会打印 PASS/FAIL 与紧固件清单）
cd cad && ../.venv/bin/python build.py

# 2) 出预览图（out/render_*.png）
../.venv/bin/python render.py

# 3) 跑固件单元测试（不需要硬件）
cd ../firmware && make test
```

零件在 `cad/out/`：`joint_base.stl`、`joint_lid.stl`、`output_disc.stl`、`link_bar.stl`、`wheel_hub.stl`。
直接丢进切片软件即可，建议 PETG、0.2mm 层高、4 层壁。

## 这套设计的三条主张

1. **接口先于形态**：所有零件的连接面都是同一套 20mm M3 网格 + 同一种螺钉。
   换构型时改的是"用哪几块板"，不是"重新设计机器人"。
2. **免测量优先**：舵机靠"浅槽限位 + 盖板压住"固定，**不依赖舵机侧面安装孔的精确位置**
   （官方 2D 图未提供孔位坐标，强行按猜测画孔，打印出来一定装不上）。
3. **间隙是设计值**：旋转件与固定件之间留 0.6mm、舵机与盖板留 0.4mm，
   自检脚本会把每一条间隙算出来并断言，而不是靠打印完试装发现蹭。

## 一件必须说清楚的事

`cad/params.py` 里每个尺寸都标了证据等级：

- `[DS]` = 官方规格书原文，可直接引用
- `[TODO]` = 标称值，**没有实物卡尺验证过**
- `[DESIGN]` = 本设计自定

目前 `[TODO]` 的核心项有 3 个：花键露出高度、舵机侧翼的真实轮廓、原厂舵盘的孔位。
这三项决定输出盘能不能真的咬住花键。**拿到舵机后第一件事是量这三个，改 params 重跑 build.py。**

## 已知不能替代的部分

本仓库能给出图纸、脚本、协议实现和自检结论，但下面这些只能由人做：

- 卡尺实测（型号手册尺寸与实物常有 0.2–0.8mm 出入）
- 打印试配、拧螺丝手感、插拔寿命
- 上电、冒烟、堵转、温升与噪声实测

详见 `docs/05-测试计划.md` 的"人必须亲手做的 12 项"。
