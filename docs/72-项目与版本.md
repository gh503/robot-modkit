# 72 · 多项目、版本快照与 schema 迁移

> 状态：**v1.20.0 已实现**（项目/版本）；总测试数已到 286。入口：Studio →“构建”→“项目”。

## 72.1 为什么改

v1.19 之前只有一个 `localStorage["modkit.design.v1"]` 草稿：

- 切换预设会覆盖当前设计；
- 只有内存里的 40 步撤销，刷新就没了；
- 旧 JSON 没有 schema 号，字段改名时只能猜。

现在改成**浏览器本地项目库**：多项目、手动版本快照、显式 schema 迁移。

## 72.2 数据模型

`localStorage["modkit.workspace.v2"]`：

```json
{
  "schema": 2,
  "active": "p_xxx",
  "projects": [
    {
      "id": "p_xxx",
      "name": "modkit-m1-standard",
      "updatedAt": "2026-10-26T...",
      "assembly": { "schema_version": 2, "components": [] },
      "versions": [
        { "at": "...", "label": "机械臂定稿", "assembly": {} }
      ]
    }
  ]
}
```

- 最多 **20 个项目**、每个项目最多 **20 个版本**；超出丢最旧。
- `active` 是上次打开的项目；启动时优先恢复它。
- 兼容旧 `modkit.design.v1`：首次启动会自动迁移成一个项目；
  保存时仍写一份旧键，旧恢复入口不会立刻失效。

## 72.3 schema 迁移

`migrateAssembly(data)` 做最小、可逆的兼容：

| 旧字段 | 新字段 |
|---|---|
| `budget` | `budget_cny` |
| `payload` | `payload_g` |
| 缺 `schema_version` | 补 `2` |
| 缺 `components[].at` | 补 `[0, 0]` |
| 缺 `components[].spin` | 补 `0` |
| 缺 `components[].parent` | 补 `null` |

迁移只补字段，不改组件 id/端口/树结构；迁移后仍走 `A.check`/`A.validate`。
分享链接、导入 JSON、预设、项目加载都会先迁移。

## 72.4 操作

- **当前项目**下拉：切换项目；`（未保存草稿）` 表示还没落盘。
- **保存**：立即写入 localStorage（编辑本来也会自动保存）。
- **另存为新项目**：复制当前设计，避免覆盖原项目。
- **删除**：删项目及版本，需确认。
- **保存版本**：给当前设计打一个命名快照；**恢复版本** 把快照载回当前项目。
- 切换预设/导入/分享会视为“新草稿”，不会覆盖已保存项目；
  第一次编辑后自动创建新项目。

## 72.5 边界

- **纯本地**：没有账号/云同步；清浏览器站点数据会丢。
- 版本是**手动快照**，不是每次编辑自动存档；自动存档只有当前项目状态。
- localStorage 配额有限；项目/版本上限 20 是硬保护，不是无限历史。
- 物理闸门仍 **0/5**。

## 72.6 验证

- `make web-smoke` 新增“项目/版本/schema 迁移”：
  保存项目、保存版本、改名、恢复版本、旧字段迁移断言；共 **10 组**。
- 静态测试检查 7 个项目/版本控件与迁移函数；总计 **311 项** pytest。
- 手工浏览器：旧 `modkit.design.v1` 首次启动迁移成功；项目切换/另存/恢复版本无脚本异常。
